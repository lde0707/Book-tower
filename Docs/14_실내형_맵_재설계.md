# 실내형 맵 — 최신 기준 안내

2026-09-26. 종전 카메라·방 설명은 [종이 백룸 통합 설계](00_종이백룸_통합설계.md)로 통합했다.

모든 공간은 책 내부의 방과 통로다. 정령이 보이는 근접 3인칭 원근 시점과 중앙 마우스 조준을 사용한다. Q/E는 월드 축에 정렬하고 이동하면 고정을 해제한다. 현재 시야에 단순히 90도를 더하는 방식은 폐기했다.
