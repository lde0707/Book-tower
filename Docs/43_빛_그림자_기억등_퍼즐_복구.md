# 빛 그림자 기억등 퍼즐 복구

2026-11-12. 사용자 요청에 따라 현재 게임의 퍼즐을 중력 상자 이전에 실제 구현되어 있던 구성으로 복구한다. 기준은 설계안 전체가 아니라 중력 개편 직전의 검증된 씬 백업이다.

## 복구한 플레이

- **F0:** 종이 덮개를 열어 빛을 보내고, 접는 다리를 내린 뒤 두 은박 반사면으로 광로를 우회시킨다. 실제 빛이 출구 잎 문양에 도달한 상태에서 걸쇠를 확인하면 문이 열린다. 다리 위 접기 금지, 낙하 복구, 해결 후 반사면을 바꿔도 열린 문 유지가 포함된다.
- **1A:** 실제 스포트라이트 아래 몸통·귀·여우 몸통·꼬리 오림을 잡고 옮기거나 뒤집는다. 조명 방향과 투영을 맞춰 토끼와 여우를 각각 기록하고, 두 기억으로 P2 문과 이름 회복 이야기를 이어 간다.
- **1B:** 기억등 충전→두 걸쇠 잠금→운반→기록대에서 방출→손잡이 회수→창 올리기와 고정→재충전→출구 방출을 복구했다. 이동 시간에 따라 빛이 줄지 않고, 출구부터 시도해도 재충전하여 복구할 수 있다.
- **나머지 방:** 백업에 있던 접이면 조합, 조각 조립, 주름 순서, 왜상과 기존 진행 연결을 복구한다. 27번 문서의 모든 확장 해법이나 후반 방 완성 아트를 새로 구현한 것으로 해석하지 않는다.

중력 운반실 16개는 씬에서 비활성화했다. 원래 배치 데이터와 생성 자산, 모바일 이식 문서는 보존한다. 일반 플레이에서는 원래 빛·그림자·등불 구성이 실행된다.

## 복구 방법과 보존 범위

원본은 `Logs/GravityMigration.verified.zip`의 `InGame-before.unity`다. SHA256은 `8308E2746CA3D75A2A57512F4CE030A8B27283FA3AB1155BD222F584379EA7B3`이다. 현재 씬 전체를 과거 버전으로 덮어쓰지 않고, 같은 객체 식별자를 이용해 필요한 레코드와 참조만 복원했다.

- 제거되었던 퍼즐 구성요소 14개와 기존 GameObject의 component 연결을 복원했다.
- 비활성화되었던 장치·상호작용·단서 오브젝트 114개를 복원했다. 이후 충돌 정리에서 제거한 중복 블록아웃 경로 13개는 다시 켜지 않았다.
- 퍼즐·문·조작부·스토리 참조 40곳, 작업책 제목·본문 필드 14곳, 방 목표 16곳을 복원했다.
- 중력 운반실 높이에 맞춰 올렸던 기존 천장 3곳을 이전 높이로 복원했다.
- 현대화된 가구 MeshCollider와 아트, 캐릭터, 카메라, 설정, 타이틀 자산을 유지했다.
- 현재 간접광 프로브와 조명 설정은 유지하고, 변경된 구조를 반영하는 환경 빛줄기 차폐 마스크 4개만 다시 계산했다. 전체 간접광 재베이크 결과로 보고하지 않는다.

복구 전 현재 씬은 `Logs/LegacyPuzzleRestore/InGame-current.verified.zip`, 차폐 마스크는 `Atmosphere-before.verified.zip`에 바이트 일치 검증 후 보존했다. `applied.json`에 변경한 식별자와 원본·결과 해시를 기록한다.

복구 도구는 `Tools/restore_light_puzzles.py`다. 인자 없이 실행하면 계획만 기록하며, `--apply`를 붙이면 원본 해시·로컬 참조·안전 백업을 검사한 뒤 씬을 수정한다. 초기 복구 직후 재실행 계획은 변경 0건으로 확인했다. 이후 사용자가 씬을 추가 편집한 상태에서는 기존 안전 백업과 불일치하면 적용을 거절한다.

## 스토리와 읽기 연결

OpeningStoryDirector는 복구한 FoldBridgePuzzle과 P2를 참조한다. F0 목표 문구는 은박으로 잎 문양에 빛을 보내는 내용, 1A 목표와 극장 대사는 토끼·여우 그림자와 등불 내용으로 되돌렸다. 첫 만남·약속·문 개방·기억·이름 회복 연출은 기존 흐름을 유지한다.

나중에 정밀 가구 충돌을 적용하면서 작업책 앞의 `장식_DarkBinding`이 읽기 조준을 막는 경우가 드러났다. 실제 조준점은 책에서 2.43m 떨어진 약 6m 폭 작업대의 앞쪽 표면이다. 작업책 가까이에 있는 상판과 해당 장식 표면을 읽기 대상으로 연결하고, 조준점이 책으로부터 3m 이내일 때만 프록시가 작동하도록 제한한다. 벽을 무시해 뒤의 책을 선택하거나 가구의 이동 충돌을 제거하지 않는다. 일반 상호작용의 거리·방 가시성 검사도 유지한다.

## 검증과 실행

검증 산출물은 `Docs/ArtReview/LegacyPuzzleRestore`에 보존한다. 에디터의 상세 입력 검사와 배포 빌드의 기능 검사를 구분한다.

- `structure-checks.txt`: 누락 스크립트 없음, 활성 중력 퍼즐 없음, 광학·그림자·기억등·문·스토리 참조, 작업책 안내와 환경 차폐 갱신.
- `f0-checks.txt`: 실제 F/마우스 광학 조작, 오답 거절, 다리 통과, 낙하 복구, 출구 개방, F0–1A 이동.
- `shadow-checks.txt`: 오림 전체 잡기, 양축 이동, 뒤집기·조명 선택·토끼/여우 기록, 기존 P2 진행과 방 숨김.
- `lantern-checks.txt`: 실제 F/마우스 충전·걸쇠·도킹·손잡이 회수와 나머지 범위 검사 조작, 오답 복구·창 고정·출구·1B 통로.
- `story-checks.txt`: 첫 이야기부터 책 읽기·문 개방·기억·이름 회복 연결 검사. 최초 실행의 가구 조준 실패와 후속 결과를 구분한다.

에디터 검사 진입점은 기존 `F0PlayVerifier.Run`, `ShadowDuetVerifier.Run`, `ReadingRoomVerifier.RunBatch`, `OpeningStoryVerifier.RunBatch`, `StorybookPassageVerifier.Run`이다. `LegacyPuzzleRestoreReview.AuditAndRefreshDepth`는 연결 점검과 환경 차폐 마스크 갱신을 수행한다.

새 빌드는 `LegacyPuzzleRestoreReview.Build`로 생성한다. 출력 폴더 이름은 배포 경로 호환을 위해 기존 `Builds/GravityPage/AFoldOfLight.exe`를 사용하지만 내용은 복구된 퍼즐이다. `-legacyQA`는 원래 퍼즐을 대상으로 한 배포 빌드 기능 검사이며 타이틀을 생략한다. `-titleQA`는 타이틀과 첫 이야기 연결을 별도로 검사한다.

후반 방의 전체 초행 플레이와 난도 평가는 자동 연결 검사나 F0·1A·1B 검사로 대신하지 않는다.
