# 플레이어와 카메라 — 현재 구현 기준

2026-09-26. 정령 모델은 PaperSpirit.prefab이며 기존 코드 오브젝트명 BookmarkBird는 호환용 이름이다.

| 항목 | 현재 값·동작 |
|---|---|
| 모델 높이 | 약 1.4 Unity 단위 |
| 이동 속도 | 5.5 단위/초 |
| 점프 높이 / 중력 | 1.2 / -18 |
| WASD | 카메라 방위 기준 이동 |
| Space | 점프·하강 중 활공 |
| 마우스 | 화면 중앙 조준 |
| F / 좌클릭 | 중앙 대상 상호작용 |
| Shift 조합 | 역방향 접기 |
| Q / E | 월드 90도 축에 관찰 고정 |
| 이동 입력 | 관찰 고정 해제 |
| Esc / 화면 클릭 | 커서 해제 / 재포착 |
| 씬 카메라 | FOV 60, 거리 4.8, 초점 높이 1.85, 피치 -2도 |

씬 직렬화 값이 스크립트 기본값보다 우선한다. 정령은 자유 비행하지 않는다. 낙하는 안전 위치로 복귀한다. 큰 방이라도 카메라 회전 공간과 접근 사거리를 확보하고, 점프는 기존 그림자 다리 퍼즐을 건너뛰지 않도록 별도 검사한다.

Idle/Move/Jump는 기존 보간 애니메이션을 유지한다. 종이 겹침 메시와 섬유 재질 보강이 적용됐다. [최신 설계](00_종이백룸_통합설계.md).
