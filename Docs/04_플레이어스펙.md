# 거인 책의 탑 — 플레이어 스펙

> 좋은 질문이었다. 지금까지 문서에 **플레이어 조작 방식이 명시된 적이 없었다.** 여기서 확정한다.

---

## 1. 결론: 플레이어 캐릭터는 **반드시 있어야 한다**

방탈출 퍼즐은 보통 커서만으로도 만들 수 있어서 "아바타 없이 가도 되지 않나"가 합리적인 질문이다. 하지만 **우리가 설계한 것들이 이미 몸을 전제로 하고 있다.**

| 설계 | 몸이 없으면 |
|---|---|
| **P15 왜상** — 드러난 실루엣이 "나와 닮았다"고 읽혀야 함 | 비교 대상이 없어 반전이 무너짐 |
| **엔딩 B** — 펼쳐진 그의 몸 위에 **앉는다** | 선택 행위 자체가 성립 불가 |
| **P1·P5·P13** — 조각을 **부리로** 물어 나름 | 조각 이동이 무미건조한 클릭이 됨 |
| **서사 전체** — 그날 밤 선대가 **어린 나를** 구하러 갔다 | 플레이어가 사건의 당사자라는 감정이 사라짐 |

즉 아바타를 빼면 이야기의 중심축이 통째로 빠진다. **책갈피새는 조작 대상이자 서사의 근거다.**

---

## 2. 조작 모델: 캐릭터 + 커서 (Tengami 방식)

| 모델 | 내용 | 판정 |
|---|---|---|
| A. 커서 전용 (The Room식) | 아바타 없이 클릭으로만 조작 | ❌ 위 4가지가 전부 깨짐 |
| B. 완전 캐릭터 조작 | 이동·상호작용 전부 캐릭터로 | △ 접기 같은 정밀 조작이 답답해짐 |
| **C. 캐릭터 + 커서** ✅ | 이동은 캐릭터, 접기·물기는 커서 | **채택.** Tengami가 검증한 모델 |

---

## 3. 이동 설계 — 자유 비행은 **금지**

새라고 해서 자유롭게 날게 하면 안 된다. 퍼즐 설계가 무너진다.

| 자유 비행을 허용하면 | 깨지는 퍼즐 |
|---|---|
| 어디든 갈 수 있음 | **P15** — "그 시점은 허공이라 도달 불가"라는 전제가 붕괴. 이 게임 최고의 퍼즐이 사라짐 |
| 끊긴 길을 그냥 넘어감 | **P3** — 그림자로 길을 잇는 이유가 없어짐 |
| 방을 자유롭게 오감 | **P4** — 두 방을 오가는 예측 강제가 무의미해짐 |

**따라서 이동은 표면 구속형으로 한다.**

| 규칙 | 내용 |
|---|---|
| 기본 이동 | 페이지 **표면 위를 걷는다** (붙어 있는 면을 따라) |
| 활공 | **짧은 거리만** 활공 가능. 상승 불가, 하강만 |
| 착지 | 빛이 닿는 면에만 착지 가능 (빛=존재 규칙이 이동에도 적용됨) |
| 낙하 | 탑 밖으로 떨어지면 마지막 안전 지점으로 복귀 (사망 없음) |

마지막 항목이 중요하다 — **이 게임에 죽음은 없다.** 실패는 시간 손실이지 진행 손실이 아니다(전역 규칙).

---

## 4. 동사(Verb) 목록 — 딱 5개

| 동사 | 입력 | 용도 | 제약 |
|---|---|---|---|
| **이동** | `WASD` / 방향키 | 페이지 표면 이동 | 표면 구속 |
| **활공** | `Space` | 짧은 하강 이동 | 상승 불가 |
| **물기 / 놓기** | 좌클릭 | 조각 운반, 홈에 끼우기 | **한 번에 1개** |
| **접기 / 펴기** | 좌클릭 **드래그** | 접이면 4단계 조작 | 접이면 근처에서만 |
| **깨우기** | 좌클릭 (주름 위) | 에코 재생 | 활성 주름만 |
| *(엔딩 전용)* **앉기** | `Space` (전임 위) | 엔딩 B 선택 | 최종 장면에서만 |

**카메라**: `Q` / `E` 로 90° 스냅 회전.

> ⚠️ **카메라 회전 시 이동 입력도 화면 기준으로 재매핑해야 한다.** 안 하면 회전 직후 조작 방향이 뒤집혀서 멀미가 난다. 스냅 회전 게임의 대표적 초보 실수다.

## 5. 물기 규칙 상세

퍼즐마다 필요한 조각 수가 다르다(P1은 2개, P5는 3개, P13은 7개). 한 개씩만 물 수 있는데 7개를 옮기라고 하면 노동이 된다. 그래서:

| 상황 | 처리 |
|---|---|
| 조각을 물고 **유품함에 넣으면** | 보관됨. 이후 언제든 재열람·재사용 (전역 규칙: 모든 단서 재열람 가능) |
| 물기는 언제 쓰나 | 조각을 **실제로 어딘가에 끼워 넣는 순간**에만 |
| 필수 조각을 떨어뜨리면 | 자동 회수 (분실 불가 — 전역 규칙) |

즉 **"운반"은 노동이 아니라 마지막 한 동작**이다.

## 5-1. 시점 — 디오라마형 3인칭

3인칭이 맞다. 단, **추격형(over-the-shoulder) 3인칭이 아니라 조망형**이다.

| 3인칭의 종류 | 우리 게임 |
|---|---|
| 추격형 (캐릭터 뒤에 카메라 밀착) | ❌ 공간이 안 보여서 퍼즐이 성립 불가 |
| **디오라마형 (공간을 조망, 캐릭터는 그 안의 작은 존재)** | ✅ **채택** — Monument Valley · Tengami · Fez 계열 |

**카메라의 주인공은 캐릭터가 아니라 공간이다.** 이유는 퍼즐이 전부 공간을 봐야 풀리기 때문이다.

| 퍼즐 | 봐야 하는 것 |
|---|---|
| P2 · P4 | 그림자가 **어디에** 지는지 |
| P13 | 조각의 그을음 각도가 **서로** 어떻게 다른지 |
| P15 | 흩어진 조각들이 **정렬되는지** — 캐릭터가 아니라 방 전체를 봐야 함 |

### ⚠️ 그런데 카메라를 완전히 고정하면 안 된다

여기가 미묘하다. 카메라를 방 단위로 **완전 고정**하면 플레이어가 시점을 고를 수 없고, 그러면 **P15의 "시점 확보"라는 퍼즐 자체가 사라진다.**

따라서:

> **시점 = 캐릭터 위치 + 스냅 각도.**
> 카메라는 캐릭터를 **느슨하게** 따라가고(밀착 추적 금지), 회전만 플레이어가 90° 단위로 고른다.

이렇게 해야 P15가 성립한다 — 정렬이 맞는 자리는 캐릭터가 갈 수 없는 허공이고, 그래서 **공간을 접어 그 자리를 캐릭터 쪽으로 끌어와야** 한다.

| 카메라 규칙 | 값 |
|---|---|
| 투영 | Orthographic |
| 추적 | 캐릭터를 느슨하게 따라감 (데드존 있는 부드러운 추적) |
| 회전 | `Q` / `E` 로 90° 스냅 4방향 |
| 줌 | 고정 (자유 줌은 정렬 판정을 흔듦) |
| 예외 | P15 왜상 해소 순간에만 천천히 뒤로 물러남 |

## 6. 캐릭터 표현

| 항목 | 설계 |
|---|---|
| 실루엣 | **단순하고 즉각 식별 가능하게** — P15 왜상이 이 형태로 해소되므로 (아트 컨셉 문서와 동일 요구) |
| 애니메이션 | 뼈대 없이 **종이 접힘 단위 회전**. 걷기는 종이가 까딱이는 느낌 |
| 감정 | 표정 없음. **고개 각도 · 날개 접힘 · 정지 시간**으로만 |
| 색 | 종이보다 한 톤 어둡게 + 리본만 미세한 채도 (플레이어 식별성) |

## 7. 프로토타입에서 플레이어가 필요한 시점

바로 만들 필요는 없다.

| 단계 | 플레이어 필요? | 대체 |
|---|---|---|
| 1. 접이면 프리팹 (4단계 스냅) | ❌ | 디버그 키로 접힘 구동 |
| 2. 주광원 + 그림자 확인 | ❌ | 씬 뷰로 눈으로 확인 |
| 3. 판정 로직 분리 | ❌ | 콘솔 출력으로 검증 |
| 4. **P2 회색 박스 조립** | ✅ **필요** | 캡슐 하나로 시작 (이동만 되면 충분) |

**P2가 "다른 위치에서 목표를 확인하고 돌아와 접는" 퍼즐이라, 이동이 있어야 검증이 된다.** 그전까지는 없어도 된다.
