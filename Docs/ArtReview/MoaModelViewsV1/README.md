## 재질·형태 기준

- 큰 둥근 머리와 통통한 몸통, 짧은 다리, 작은 종이 부리, 검갈색 타원 눈.
- 따뜻한 아이보리 장지, 미세한 섬유, 얕은 구김, 무광 표면. 종이 정령과 같은 재료 계열을 목표로 한다.
- 날개는 넓은 잎 모양 종이 세 겹, 꼬리는 접은 종이 세 장. 실사 깃털로 바꾸지 않는다.
- 원본에서 보이지 않는 등·배·발바닥·반대 날개는 같은 종이 공예 구조로 해석해 보완했다.

## 모델링 배치

모델의 위를 +Y, 부리 방향을 +Z로 잡는다. 위쪽 참고는 +Y 카메라, 아래쪽 참고는 -Y 카메라로 보고 두 이미지 모두 화면 위를 +Z로 맞춘다. 이 때문에 같은 왼쪽 날개가 위쪽 이미지에서는 화면 왼쪽, 아래쪽 이미지에서는 화면 오른쪽에 보인다. 왼쪽 측면 카메라는 -X, 오른쪽은 +X다.

각 파일은 별도로 생성한 참고 그림이므로 픽셀 치수와 종이 접힘까지 정확히 일치하는 CAD 투영도는 아니다. 모델링할 때 머리·몸통 중심, 눈 높이, 날개 뿌리, 발의 바닥선을 공통 기준으로 맞춘다. 골격과 기본 몸통은 하나로 만들고 비대칭 날개 장식만 분리한다. 원본 새와 정령 스프라이트 및 기존 Unity 모델은 변경하지 않았다.
