# 종이 에셋 적용 기록

## 현재 진행 상태

실제 레이아웃 기준 16개 구역, 경사로 14개, 퍼즐 11개와 잠긴 출구 11개다.
접기 조합, 조각 복원, 주름 순서가 구현되어 있다. 문서의 초기 집계(퍼즐 10개)는 현재 데이터보다 오래됐다.
P15 왜상 정렬과 P16 엔딩 선택은 여전히 별도 구현 대상이다.
빛/그림자는 실제 조명으로 보여 주지만 접기 퍼즐 정답은 패널 상태 조합으로 판정한다.
이번 작업은 그 판정이나 이동 능력을 바꾸지 않는다.

## 적용 에셋

- `Assets/_BookTower/Generated/Paper/PaperFairy.prefab`: 직접 생성한 UV 종이 요정 메시, 잉크 눈, 붉은 책갈피 리본. 기존 GhostRig로 부유·이동 기울기·리본 흔들림을 사용한다. 캐릭터 충돌체와 이동 규칙은 유지한다.
- `BoundBook.prefab`, `BoundBook_0/1/2.asset`: 두 표지·책등·안으로 들어간 속지의 메시. 기존 서가의 spine 재질 장식 5,709개에 적용한다. 원래 상자의 바깥 크기를 넘지 않고, 축별 메시를 공유한다. 콜라이더와 RoomWall 동작을 그대로 사용한다.
- `PaperWall.prefab`: 기존 팔레트를 사용하는 재사용 가능한 종이 벽 모듈.
- `T_Paper_Normal.png`: 기존 종이 섬유 텍스처에서 생성한 타일링 노멀맵. URP Lit의 낮은 강도로 벽·종이 에셋에 적용한다. 투명도를 쓰지 않아 그림자를 유지한다.

원본 외부 정령은 삭제하지 않았다. 현재 InGame 생성기는 새 요정을 사용한다.
모델과 프리팹, 재질은 씬 외부 에셋으로 저장해 다시 열어도 유지된다.

## 맵 틈 수정

문을 자른 뒤 0.4m 이하 벽 조각을 버리던 규칙을 제거했다. 실제 데이터에서 1D 남쪽 외벽의 0.06m 조각이 복구된다.
천장 분할도 0.05m 이하의 유효한 조각을 버리지 않도록 바꿨다. 현재 천창 배치는 유지된다.
분리 바닥 생성은 전역 floorGap 대신 해당 방의 splitGap을 읽어 데이터와 지오메트리가 일치하게 했다.
P3 간극과 해결 후 상승하는 다리, 빛을 통과시키는 천창은 의도된 구멍으로 유지한다.
카메라 쪽 벽이 사라지는 것은 RoomWall의 디오라마 연출이며, 그림자와 충돌은 남는다.

## 재생성

1. `python -X utf8 Tools/level_layout.py validate`
2. `python -X utf8 Tools/level_layout.py build`
3. Unity `Book Tower > InGame 씬 구성하기`

텍스처 원본은 `Tools/make_textures.py`, 메시 원본은 `PaperAssetBuilder.cs`다.
배치 실행 진입점 `BookTower.EditorTools.PaperAssetBuilder.BuildAndReview`는 씬을 저장한 뒤 별도 메모리 씬에서 에셋 미리보기를 만든다.
`paper-assets.png`는 에셋 확인용 조명이고, `room-1A.png` / `room-1D.png`는 저장된 게임 씬에서 방을 고립해 촬영한 편집기 렌더다.
이 렌더는 플레이 모드 조작 테스트를 대체하지 않는다.

## 검증

레벨 검사: 오류 0, 기존 경고 7(긴 경사로 1, 룸 컬링 관련 시야 5, 가시성 검사로 차단되는 원거리 상호작용 1).
회귀 검사 `Tools/test_paper_geometry.py`: 천장의 얇은 테두리 보존, 모든 방의 천창 제외 면적 분할, P3 해결 다리 유지.
전체 게임의 수동 클리어 테스트는 수행하지 않았다.
