# 정령 종이 모자 — 깊게 눌러쓴 꼬깔

기준: `ArtSource/TitleConcepts/title-hero-integrated-v3.png`의 종이 꼬깔. 기존 얼굴·몸통·망토는 유지하고 모자를 실제 메시로 다시 제작했다.

- 둥근 후드를 넓은 챙에서 말린 꼭대기까지 연결된 꼬깔 곡면으로 교체.
- 피드백 반영: 전체 모자를 0.105 모델 단위 내려쓰고, 옆 챙을 추가로 낮춰 이마와 옆머리를 가림. 눈은 정면에서 보이도록 전면 챙에 여유를 둠.
- 큰 비대칭 굴곡과 작은 불규칙 구김을 겹쳐 가장자리 실루엣을 구성.
- 4개 겹침 띠, 9개 접힌 면, 얇은 안쪽 종이 면과 가장자리 섬유. 베이크만으로 흉내 낸 장식이 아닌 실제 기하 구조.
- 기존 17본·9개 60 Hz 클립에 스킨 가중치를 다시 이식. 모자 끝은 높이에 따라 HoodTip 본 가중치를 점진적으로 부여.
- 2048px 색·노멀·거칠기 재베이크. 기존 Unity FBX 경로와 메타 GUID를 유지해 씬과 프리팹 참조를 보존.

## 파일

- `01-three-quarter.png`, `02-front.png`, `03-rear-game-view.png`: 실제 Blender 메시 렌더. 생성형 컨셉 이미지가 아님.
- `08-export-verified.png`: GLB를 다시 불러와 렌더링한 게임용 베이크 재질 확인.
- `export-check.json`, `rig-check.json`: 재반입 크기·메시 유효성, 스킨 이식과 애니메이션 정보.
- `import-check.txt`, `play-check.txt`, `unity-ingame.png`: 별도 검증 프로젝트에서 현재 InGame 씬의 참조·애니메이션 상태·게임 조명 확인.

## 재생성

Blender 5.1에서 `Tools/refine_spirit_hat.py -- model`, `-- bake`, `-- rig` 순서. 리깅 출력은 우선 `Logs/F0ArtValidation` 프로젝트로 내보내며, 검증 후 FBX와 텍스처만 실제 프로젝트에 복사한다. V1 원본은 보존한다.

타이틀 이미지와 같은 일러스트의 미세 묘사를 그대로 복제한 것은 아니다. 게임에서 읽히는 실루엣, 겹침과 굴곡을 우선 반영했다. 현재 고밀도 캐릭터 메시이며 LOD 최적화는 별도 작업이다.
