# 이어지는 1인칭 깨어남

첫 만남을 4장의 전체 화면 교체에서 하나의 연속된 2D 장면으로 변경했다. 새 몸, 날개, 정령 손, 빛 씨앗을 내장 image_gen으로 따로 제작하고 유니티 RectTransform으로 움직인다. 프롬프트는 prompts.json에 기록했다.

- 새가 오른쪽에서 다가온 뒤 몸의 가로 위치와 크기를 유지한다.
- 날개가 어깨를 축으로 부드럽게 펴진다.
- 날개 끝의 씨앗이 정령의 손 쪽으로 이동하며 커진다.
- 손이 화면 아래에서 올라오고 빛이 스며든 후 새가 날개를 접는다.
- 대사가 바뀌어도 빛 전달 시간은 초기화하지 않는다. 일시정지에서는 멈춘다.

continuous-awakening.mp4는 유니티의 동일 렌더링 코드를 30fps로 캡처한 12초 무음 연출 미리보기다. 동작 확인을 위해 대화창은 제외했다. 처음 2초에 두 번째 대사, 4초에 빛 전달 대사, 7초에 깨어나는 대사로 넘어가도록 재현하여 대사 경계에서도 빛이 이어지는지 보여 준다.

적용 범위: F0 첫 만남 전체. F0 완료와 1A의 별도 기억 장면은 유지한다. 모든 연출은 2D 레이어 애니메이션이며 새로운 3D 리깅은 아니다.
