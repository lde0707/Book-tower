# 스케치북 세계 — 전체 아트 개편

2026-09-25. 기준: `02_아트컨셉.md` 최신 개정과 사용자가 선택한 둥근 종이 정령.

## 적용

- InGame 16개 방 전체의 벽·바닥·책 장식에 정령과 같은 PaperFiber 계열을 적용했다. 큰 연필 해칭과 과한 노멀을 줄였다.
- 책장 중심 장식을 말린 낱장과 큰 책 중심으로 바꾸었다. 장식은 3,317개이며 책장 비중·바닥 흩뿌림·반복 밀도를 줄여 퍼즐 주변 여백을 확보했다. 층별 파손/낱장/책의 차이는 유지한다.
- 벽 낱장은 상자에서 얇고 끝이 말린 메시로 변경했다. 일반 연필 외곽선은 0.018, 장식은 0.009 월드 단위로 통일했다.
- 배경은 `#FDFCFA` 백지, 종이는 `#FBFAF6`/`#F2EFE7`, 책 표지는 낮은 채도의 크레파스 계열이다. 정령은 둥근 머리·말린 꼬리·`#D9694F` 리본과 기존 부드러운 애니메이션을 유지한다.
- 종이의 약한 확산광 표현을 재질에 추가해 그늘이 회갈색 덩어리로 눌리지 않게 했다. 고정 방향광과 실제 그림자 투영을 보존한다.
- 모든 방의 접이면에 점선 주름과 접힌 귀를 적용했다. 1A의 목표 윤곽과 대응 표식을 보존했다.
- 1B 기본 시점을 옆으로 바꿔 접힌 면 뒤에 가려졌던 그림자 다리가 보이게 했다.
- 3A 카메라 초점을 높여 왜상 머리가 화면 위로 잘리지 않게 했다. P15 판정은 정령이 접이면 근처에 있고 전체 실루엣이 화면 안에 있어야 성립한다.

## 기능 검증

배치 검사: **오류 0건 / 경고 9건**. 장거리 경사로, 방 간 조감 가림(룸 컬링 적용), 2F 문과 그림자 판독 벽 겹침, 1B 천창 비율 경고는 남아 있다. 모든 구멍이나 전 구간 플레이가 해결됐다는 의미는 아니다.

Unity Play Mode 검증은 실제 F 입력, 기존 상호작용, CharacterController 이동을 사용한다. 1A 성공과 문 개방, 1B 입구 접근·오답 거절·그림자 투영 안에 들어가는 다리 메시·광원 경로·실제 횡단, P15 점화 선행 조건·잘못된 시점/접힘 거절·정렬 판정을 확인한다.

P13/P14는 P15를 분리 검증하기 위해 테스트에서 직접 완료시킨다. 따라서 이 결과는 전체 게임 완주 검증이 아니다. 최종 실행 결과는 [Play Mode 보고서](Direction/play-verification.txt)를 기준으로 한다.

## 남은 한계

HUD 없이 초행 플레이어가 목표·조작 대상·성공 이유를 이해하는지는 별도 사용자 관찰이 필요하다. P15는 실제 방 표면에 붙은 흑연 실루엣 메시이며 광원이 만드는 실루엣 그림자 자체가 아니다. 역방향 빛 추적 연출과 엔딩 연결은 아직 완성하지 않았다.
