# 1A 팝업북 회랑 — 구현과 검증

기준: 사용자가 제공한 《잊힌 제목》 전 방 콘셉트의 1A, 두 번째 방 레퍼런스 이미지.

## 적용
- InGame 씬의 기존 1A 위치(100, 4, -180)를 유지했다.
- 버터 옐로 종이 바탕, 코럴·청록 동물 그림과 압화, 별 조명, 그림책 더미.
- 세 연속 공간을 겹친 종이 아치로 구분했다. 이동 바닥과 장식용 종이 메시를 분리했다.
- F0→1A 기존 경사로에 곡면 책장 천장, 제본 장식, 잎무늬와 별 조명을 덧붙였다. 기존 잠금·다리 연결은 유지했다.
- 세 접이면 조합 [2,1,3]으로 기존 P2를 연결했다. 하나 또는 두 개만 맞추면 완료되지 않는다.
- 최종 토끼는 두 실루엣을 접기 상태에 따라 이동·회전시키는 연출이다. 실제 광학 투영이나 그림자 픽셀 판정은 아니다.
- 동물들에게 이름을 붙이는 기억은 그림책·세 동물의 정물 장면으로 표현했다. 문장 수집이나 회상 컷신은 이번 모델링 범위에서 새로 구현하지 않았다.

## 파일 기반 실행
Unity 6000.3.10f1 배치 모드:
- 모델 적용 및 캡처: BookTower.EditorTools.StorybookRoomBuilder.RunBatch (-quit)
- 플레이 검증: BookTower.EditorTools.StorybookPlayVerifier.RunBatch (-quit 없이 실행; 검사 종료 후 자동 종료)
- structure-check.txt: 연속 바닥 및 접이면 개수 검사
- play-check.txt: 실제 실행 결과. FAIL인 경우 검증 완료로 보지 않는다.

## 범위와 한계
씬의 모델·색·통로에 적용했다. 레퍼런스와 동일한 사진적 질감을 재현한 것은 아니다. 생성 프리팹은 배경 재사용용이며, 퍼즐 연결은 저장된 InGame 씬을 기준으로 한다.

## 최종 확인 결과
- 배치 빌드 성공, 바닥 567개 지점 통과.
- 플레이 모드에서 F0 연결 통로, 두 아치, 1B 출구까지 이동 성공.
- 접이면 하나 또는 둘만으로는 미완료, 세 조합에서 P2 완료 확인.
- 토끼 그림자 반쪽 정렬 확인.
- 아치 면 방향, 별 조명, 천장 접합, 책더미 충돌체 표시 문제 수정.
- 1B 방향 다리의 방 안쪽 측벽 돌출을 제거했다. 다리 바깥쪽 측벽은 유지했다.
- 이후 통로 재질 및 장식 면 간격을 보정했다. 이 마지막 보정은 충돌체와 퍼즐 로직을 변경하지 않았다.
