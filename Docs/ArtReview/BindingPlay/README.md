# F0 — 살아있는 제본실

2026-09-26 최초 적용 기록. **이후 F0 퍼즐 교체로 선택적 고리 3개와 문 솔기 빛은 비활성화하고 나머지 놀이를 높은 대지 위로 옮겼다. 최신 상태는 [접는 다리 구현](../FoldBridge/README.md)을 따른다.** 아래는 최초 적용 당시 설명이다.

중앙 조준으로 가까운 대상을 보고 F 또는 왼쪽 클릭으로 상호작용한다. 최대 거리는 3.5m다.

| 요소 | 개수 | 반응과 역할 |
|---|---:|---|
| 제본 고리 | 3 | 당김/해제, 작은 흔들림, 문 솔기로 이동하는 빛과 도착 조명. 제본실의 연결감을 보여준다. |
| 소리를 내는 책 | 3 | 각기 다른 음높이와 책등 흔들림. 정답과 무관하게 만져 보는 놀이. |
| 먼지 쪽지 | 1 | 먼지가 줄어들며 금빛 잎 인장 발견. 작은 탐색 보상. |
| 자유 페이지 | 1 | 종이 소리와 감쇠하는 펄럭임. 종이의 가벼움을 표현. |
| 매달린 책갈피 | 3 | 평소 미세하게 흔들리고, 퍼즐 해결 후 움직임 확대. |
| 문 솔기 조명 | 3 | 고리 반응 및 퍼즐 해결 시 순차적으로 밝아짐. |

기존의 두 조각 수집 → 조립 → 문 개방은 유지한다. 고리는 선택적 놀이이며 하나를 풀어 놓아도 진행할 수 있다. 설계 문서의 세 매듭 순서 퍼즐은 아직 구현하지 않았다. 밧줄은 물리 시뮬레이션이 아닌 정해진 애니메이션과 빛 경로를 사용한다.

새 WAV 세 종류는 Tools/make_binding_audio.py로 합성한 효과음이다. 상호작용 소리는 거리 감쇠가 적용되며 숨겨진 방에서는 중지된다. 상태 보존은 현재 플레이 세션에 한정된다.

재생성: InGame을 연 뒤 Book Tower/F0 동적 상호작용 적용 메뉴. 전체 씬을 처음부터 생성한 경우 기본 F0 아트 이후 이 패스를 적용한다. 기존 F0 아트만 재생성할 때는 동적 계층을 보존한다.

검증: F0PlayVerifier.RunBindingBatch. 중앙 조준, 가상 키보드 F와 마우스 클릭, 거리/숨긴 방 차단, 각 요소 반응, 조명 도착, 기존 조각 수집과 문 개방 및 출구 이동을 검사한다. 첫 고리 외 요소의 반응은 직접 API 호출 검사다. 소리의 청감 품질과 초행 플레이의 재미는 자동 검사로 판정하지 않는다.
