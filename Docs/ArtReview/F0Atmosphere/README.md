# F0 창빛과 분위기

2026-09-27, InGame 씬에 저장했다. `player-overview.png`, `player-pillar.png`는 플레이 모드의 실제 플레이어 카메라 캡처다.

- 왼쪽 창의 크림색 주광을 강화하고 높은 곳에서 대각선으로 떨어지도록 방향을 조정했다. 오른쪽 창빛은 약하고 중성에 가깝게 설정했다.
- 기둥 앞면과 후면을 향하는 그림자 없는 보조광 세 개를 추가해 종이 표면에서 오는 반사광을 근사했다. 실내 중앙의 점광원은 낮춰 바닥의 과한 밝기를 줄였다.
- 어두운 곳의 형태가 보이도록 F0의 주변광을 올리고, 과한 대비·채도를 낮췄다. 호박색 종이 등과 약한 블룸으로 따뜻한 강조점을 유지했다.
- 창가에 여섯 개의 가장자리가 흐려지는 반투명 빛줄기와 최대 170개의 작은 종이 먼지 입자를 추가했다. 입자는 천천히 움직이며 수명에 따라 나타났다 사라진다.
- 분위기 요소에는 충돌체가 없다. 기존 퍼즐 광선과 상호작용 코드는 바꾸지 않았다. 효과와 추가 조명은 F0 하위에 있어 방 표시 제어에 포함된다.

## 구현 범위

이번 단계는 실시간 조명, 색보정, 반투명 메시와 파티클로 만든 분위기 연출이다. 빛줄기는 물리적인 볼륨 산란이 아닌 근사 표현이며, 새로 베이크한 GI나 반사 프로브는 포함하지 않는다. 레퍼런스와 동일한 결과 또는 성능 수치를 보장하지 않는다.
