# F0 · 생활 도구에 통합한 빛 퍼즐

2026-09-28

독립적인 사각 은박판 3개를 제본실에서 실제 쓰이는 물건으로 바꾼다. 반사 법칙과 성공 조건은 유지하고, 물건의 용도·재질·작동 연결을 읽을 수 있게 하는 환경 통합 작업이다. 이번 수정은 새 퍼즐 단계나 난이도 확장이 아니다.

| 기존 | 새 외형 | 조작과 단서 |
|---|---|---|
| 입구 은박판 | 천장 건조 레일에 매단 은박 속지 제본책 | 붉은 책갈피의 실감개를 감으면 책이 이동·회전. 양쪽 매다는 실은 책을 따라 움직임 |
| 고정 모서리 반사판 | 적갈색 종이를 접은 등불 반사갓의 은박 안감 | 조작하지 않는 환경 반사면. 같은 은박 재질로 같은 반사 규칙을 암시 |
| 건너편 은박판 | 낮은 제본 서가 위 회전 책받침의 은박책 | 적층책과 가구에 연결된 회전축, 서가 앞 실감개로 회전 |
| 같은 고리 받침대 | 덮개 책갈피·제본 실감개 | 각각의 물건을 설명하는 이름과 동작 안내로 변경 |

작업책에는 ‘종이는 빛을 멈추고 은박은 방향을 바꾼다’, ‘말리는 책·등불 안쪽·서가책에 같은 재료를 쓴다’, ‘빛이 멎은 곳을 따라간다’는 관찰 단서를 넣는다. 순서나 회전 횟수를 정답으로 알려주지 않는다.

실제 반사면의 Transform·콜라이더·퍼즐 참조와 광선 계산을 보존한다. 새 책표지와 안감이 원래 광학 면을 감싸며, 가구는 다리와 광선 경로 바깥에 배치한다. 별도 생성 메시 폴더만 사용하며 방 전체를 다시 생성하지 않는다.

적용 메뉴: Book Tower > F0 빛 장치를 제본실 소품에 통합.
원본 에디터 큐: Logs/f0-editor.request에 embedded-optics. 편집 모드에서 적용하며 현재 씬을 Logs/EmbeddedOpticsBackups에 먼저 보관한다.

검증: 별도 Unity Play에서 41개 PASS 행. 덮개 닫힘/재개, 반사면 회전, 잘못된 경로, 문 개방, 다리 통행과 1A 통로 이동을 확인했다. 최종 캡처는 overview.png 및 각 소품 이름의 PNG. 원본 씬은 변경된 YAML 오브젝트의 이전 값이 모두 일치함을 확인한 뒤 해당 오브젝트만 병합했다. 기존 전체 씬 백업은 Logs/EmbeddedOpticsBackups에 보존한다.

메시 갱신 시 기존 GPU 버퍼를 명시적으로 비운 뒤 정점/인덱스/노멀/UV를 갱신하도록 수정했고, 반사갓 전체 면이 정상 렌더되는 최종 캡처를 확인했다. 열려 있는 원본 Unity 편집기는 백그라운드 갱신이 지연되어 씬 파일 재로드가 필요할 수 있다.
