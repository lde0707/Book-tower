# 피아노·바이올린 버전

세 구역용 원곡을 직접 합성한 피아노와 찰현악기 음색으로 편곡했다. 실제 연주 녹음이나 샘플 악기 라이브러리는 사용하지 않았다.

| 구역 | 템포 | 길이 | 구성 |
|---|---|---|---|
| F0·1 | 82 BPM | 58.5초 | 따뜻한 피아노 분산화음과 밝은 바이올린 선율 |
| 2 | 80 BPM | 60초 | 단조의 차분한 선율과 규칙적인 피아노 반주 |
| 3 | 86 BPM | 55.8초 | 조금 더 밝고 진행감 있는 마무리 |

CalmV2의 62~66 BPM보다 템포와 반주 밀도를 올렸다. 타악기와 벨은 넣지 않았다. 평균 RMS는 -22 dBFS로 유지하며 잔향을 루프 시작으로 연결했다. 클리핑과 루프 경계 변화량을 코드로 검증했다. 직접 청음 검증을 했다는 의미는 아니다.

게임용 WAV는 기존 파일을 사용하는 Unity의 파일 잠금을 피하도록 `_PianoViolinV3.wav`라는 별도 파일로 저장하고 RegionMusic.asset 참조를 교체했다. 다음 재생 시작에 새 음원이 로드된다. 기존 음악은 보존한다. 듣기용 MP3는 이 폴더의 Region1~3_PianoViolin.mp3다.

작곡 스크립트: Tools/compose_region_music_duet.py
기술 검증: audio-check.json
