# 구역별 배경음 적용

- F0 및 1구역: `Region1_PaperLanterns.wav` (60초)
- 2구역: `Region2_FadedMemories.wav` (약 62.6초)
- 3구역: `Region3_TitleInTheLight.wav` (57.6초)

기존에 제작한 음원을 그대로 사용한다. PaperUI 시작 시 Resources/RegionMusic 라이브러리를 읽어 재생하며, 라이브러리가 정상 연결되면 임시 QuietPages 음악은 재생하지 않는다. 기존 환경음은 유지한다.

같은 구역의 방 사이에서는 재시작하지 않는다. 구역이 바뀌면 2.5초 동안 교차 페이드한다. 각 곡은 반복 재생하며 설정창의 음악 볼륨, 전체 볼륨, 일시정지 정책을 따른다. 라이브러리의 기준 볼륨은 0.5다.

검증: 별도 Unity 검증 프로젝트의 InGame 씬에서 Play 모드로 시작 재생, 임시 음악 중복 방지, 구역 매핑, 동일 구역 연속 재생, 구역 전환, 루프 경계, 음악 볼륨, 일시정지 중 페이드 정지를 확인했다. 결과는 play-check.txt에 기록했다. 에디터 검색 인덱스 초기화에서 UnityEditor.Search 예외가 한 차례 있었으나 음악 검증은 통과했다. 실제 스피커 출력의 청음 검증은 수행하지 않았다.
