# 잔잔한 구역별 배경음 v2

기존 세 곡의 음원 파일을 같은 경로와 GUID로 교체했다. RegionMusic 라이브러리의 구역 매핑, 음악 설정 연동, 2.5초 교차 페이드는 유지된다. 기존 WAV는 ArtSource/RegionMusicV1에 보관했다.

| 구역 | 분위기 | 템포 | 길이 |
|---|---|---|---|
| F0·1 | 종이등 아래: 따뜻하고 조용한 시작 | 64 BPM | 60초 |
| 2 | 희미한 기억: 차분하고 사색적인 화음 | 62 BPM | 약 62초 |
| 3 | 마지막 장의 빛: 긴장이 풀리는 부드러운 마무리 | 66 BPM | 약 58초 |

벨·브러시 타악기·촘촘한 아르페지오를 제거했다. 부드러운 시작과 끝을 가진 화음, 낮은 음역의 드문 선율을 직접 합성했다. 금속성 비정수 배음과 디튠 효과를 쓰지 않는다. 곡당 음 이벤트는 기존 526~586개에서 92개로 줄었다. 평균 레벨은 RMS -18.4 dBFS에서 -23 dBFS로 약 4.6 dB 낮췄다. 이 값은 체감 음량을 나타내는 LUFS 측정값은 아니다.

루프 밖으로 넘어가는 잔향은 시작 구간에 연결했고 주기적 필터로 경계를 유지했다. WAV는 게임용 스테레오 44.1kHz/16bit이며 MP3는 듣기용이다. MP3 플레이어의 반복 지연과 게임 WAV 루프는 다를 수 있다.

검증: PCM 길이, 최대 진폭, 루프 경계 변화량, 주파수 에너지를 코드로 확인했다. 클리핑 없음. 결과는 audio-check.json. 청감의 편안함은 사용자 청취 평가가 필요하며 직접 청음 검증으로 보고하지 않는다.
