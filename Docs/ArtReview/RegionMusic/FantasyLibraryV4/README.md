# 《잊힌 제목》 판타지 도서관 BGM V4

직접 작곡한 오리지널 악기 합성 음악 5곡. 실제 악기 연주 녹음이나 외부 음원 샘플은 사용하지 않았다.

부드러운 피아노, 낮게 섞은 글로켄슈필, 반복 하프 아르페지오, 따뜻한 스트링 패드, 작은 브러시/탭 리듬을 공통으로 사용한다. D장조/B단조 계열과 반복되는 선율 조각이 구역들을 연결한다.

## 파일 및 사용

- 미리듣기: 이 폴더의 192 kbps MP3 다섯 개.
- Unity 원본: Assets/_BookTower/Audio/FantasyLibraryV4/*.wav (44.1 kHz / 24-bit PCM / stereo).
- WAV 전체 길이가 루프다. AudioSource.loop=true, 시작 샘플 0, 끝 샘플은 manifest.json의 loop_end_sample_exclusive를 사용한다.
- Unity 임포터는 Streaming / Vorbis quality 0.85 / stereo로 설정했다. 원본 WAV의 샘플 경계가 기준이며 MP3 미리듣기는 플레이어의 인코더 패딩 처리에 따라 반복 시 작은 간격이 생길 수 있다.
- 기존 구역 음악 라이브러리와 메인/엔딩 재생 연결은 변경하지 않았다. 이번 결과는 다섯 곡의 새 음원 파일이다.
- 재생성: Tools/compose_fantasy_library_v4.py. 각 곡의 악기별 음표는 *-score.json에 저장되어 있다.

## 검증

각 파일의 채널·샘플 수·유한 파형·클리핑·루프 경계의 샘플 변화량, FFmpeg loudnorm의 integrated LUFS / true peak / LRA를 분석했다. 노트와 리버브 잔향을 반복 구간의 앞부분에 되돌려 넣고 순환 필터링을 사용했다. 모든 곡의 피크는 -5.9 dBTP 이하, LRA는 1.4~1.9 LU다. 실제 스피커를 통한 청취 평가는 하지 않았다.
