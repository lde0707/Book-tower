# F0 문 연출 · 빛 · 조작 피드백 (2026-09-28)

- 문 양쪽 날개가 회전하는 전체 범위를 계산해 높은 정면 구도를 만든다. 0.85초 카메라 이동 후 0.95초부터 3.2초 동안 문을 연다. 완료 즉시 기존 Return 스토리로 이어지고 이후 플레이 조작이 복구된다.
- 다리의 미사용 각도는 위로 선 -90도에서 아래로 접힌 +90도로 변경했다. 펼쳐야 건널 수 있는 규칙과 실제 광선 충돌은 유지된다.
- 실제 광선 선분에 밝은 중심과 금빛 가장자리 번짐을 적용한다. 깊이 검사를 유지하여 벽을 투과하지 않는다. 방 전체 조명은 변경하지 않는다.
- 성공적으로 조작한 거울/은박 제어에는 손잡이 위치의 짧은 클릭과 물체 위치의 이동음을 분리한다. 문 소리는 카메라가 멀어져도 들리는 범위와 공간 혼합을 적용했다. 기존 효과음 설정과 일시정지를 따른다.
- 소스: 저장된 Kenney RPG Audio / Interface Sounds CC0. 편집 원본과 출처는 ArtSource/Audio/Kenney/f0-mechanism-edits.json, 재생성은 Tools/prepare_f0_mechanism_sfx.py.

## 검증

격리된 Unity 6000.3.10f1 프로젝트에서 실제 InGame 씬으로 검증했다. 원본 프로젝트에는 동일한 런타임 코드와 Resources를 적용했다.

1. F0PlayVerifier: 실제 F/마우스 입력, 모든 반사 분기, 빛 차단/복구, 다리 충돌 및 건너기, 낙하 복구, 문 열림, F0→1A 이동 PASS.
2. FoyerTransitionVerifier: 문 열리는 동안 플레이어 잠금, 문 회전 범위의 화면 포함, 문 소리 트리거, 완료 후 스토리 시작, 조작 복구, 통로 이동 PASS. 최초 캡처에서 반사책이 문 일부를 가려 카메라 높이를 수정한 뒤 재검증했다.
3. initial-sightline.png / light-route.png / door-reveal.png 실제 카메라 렌더 확인. 문 전환 테스트는 문 상태를 직접 해결 처리하므로 해당 이미지에서 퍼즐 반사면은 초기 상태다.

소리 파일은 파형/길이/피크를 검증했으며 실제 스피커 청취 평가는 수행하지 않았다.
