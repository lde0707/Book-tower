# 정령의 1인칭 깨어남 — 2026-09-27

내장 image_gen으로 현재 새와 후드형 정령 디자인을 참조해 새로 생성한 네 장의 컷이다. 배경은 어두운 종이 결로 단순화했다. 원본 이미지와 프롬프트는 prompts.json에 기록했다.

이미지: Assets/_BookTower/Art/Cutscenes/FirstPersonV1

1. 01-dark: 시야에 희미하게 들어오는 새. 정령은 보이지 않는다.
2. 02-offering: 새가 관객을 향해 날개를 열고 빛을 나눈다.
3. 03-received: 화면 아래 정령의 종이 손과 소매로 빛을 받는다.
4. 04-awake: 초점이 잡힌 새와 따뜻하게 밝아진 시야.

F0 첫 만남에 적용한다. 첫 두 대사는 거의 암전으로 유지하고, 세 번째 대사에서 1.8초 뒤 빛을 받는 이미지로 전환한다. 빛의 후광은 관객 쪽으로 확대되어 가슴 방향으로 내려온다. 네 번째 대사부터 깨어난 이미지를 유지한다. 후속 대사마다 호흡 같은 작은 화면 움직임이 이어진다. 이번 버전은 새의 관절별 애니메이션이 아닌 컷 전환, 화면 이동, 입자, 빛의 확대/잔광을 결합한 연출이다.

F/좌클릭 전체 표시와 다음 대사 입력은 기존 방식을 유지한다. 일시정지 때 연출 시간도 멈춘다. 모션 감소 설정에서는 화면 이동과 빛 확대를 줄인다. 밝은 안내 글씨와 그림자로 암전 화면에서도 입력 안내를 읽을 수 있게 했다.

awakening-motion-preview.mp4는 네 이미지의 흐름을 보여 주는 20.4초/30fps 무음 모션 코믹 미리보기다. 유니티 실시간 캡처 영상은 아니며 게임의 대사창과 실시간 후광은 포함하지 않는다. 실제 게임 화면은 unity-*.png, Play 검증 결과는 play-check.txt를 참고한다.
