# F0 레퍼런스 기반 입체 장식 적용

2026-09-27. `Assets/Scenes/InGame.unity`에 적용. 이 폴더의 PNG는 생성형 콘셉트 이미지가 아니라 수정한 Unity 씬을 카메라로 렌더한 결과다.

## 적용 내용

- 기존 약 32m 폭, 36m 깊이, 16m 높이의 실내 외곽과 퍼즐 구간을 유지하고, 큰 문·양쪽 책등 기둥·중앙 다리의 구도를 기준으로 장식 비율을 구성했다. 레퍼런스와 정확히 같은 치수로 재구축한 것은 아니다.
- 양쪽 벽에 5단 서가 6개, 제본 장서 150권, 높아진 플레이 바닥에 맞춘 장지 벽감과 두꺼운 창턱을 추가했다.
- 높이 12.4m, 반지름 1.2m의 둥근 책등 기둥 4개에 황동 띠, 리벳, 잎 양각을 배치했다.
- 큰 문 양옆에 겹친 장지 액자와 잎 문양을 배치하고 문 위와 벽 상단에는 적층 몰딩을 추가했다.
- 왼쪽 작업대에 펼친 책과 작은 책을, 오른쪽에 바퀴 달린 책 선반을 배치했다. 이번 작업의 가구는 장식이며, 책 읽기나 선반 이동 기능을 새로 구현하지 않았다.
- 입구 바닥에 종이 겹장과 테라코타 선, 제본 실을 추가하고 측면에 종이 등 두 개를 추가했다.
- 기존 종이·가죽·황동 재질을 공유한다. 중앙 광선 경로와 문 회전 영역은 유지한다.

## 확인

`front.png`, `side.png`, `wall.png`에서 구조와 배치를 확인했다. 초기 상태라 중앙 종이 다리가 세워져 있다.

`../InteriorRoomsV3/F0-play-verification.txt`의 자동 플레이 검증이 통과했다. 시작 지면, 추락 복구, 실제 F/마우스 입력, 반사 경로와 잘못된 해법, 점유된 다리 보호, 출구 확인, 문 열림, F0→1A 실제 이동을 포함한다. 모든 표면의 수동 충돌 검사나 성능 프로파일링을 완료했다는 의미는 아니다.

레퍼런스 이미지의 섬유 가장자리, 부드러운 광산란과 미세한 손작업 굴곡까지 동일한 품질로 재현한 상태는 아니다.
