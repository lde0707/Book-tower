# 1A 세 빛·두 동물 그림자 공방

> 2026-10-02 후속: 여우의 실제 조작 허용 범위와 정렬·놓기 안내는 [여우 정렬 판정 수정](../ShadowFoxAlignment/README.md)을 따른다. 아래 휠 전용 이동 설명은 과거 구현이며 현재는 마우스 두 축과 WASD로 함께 이동한다.

2026-09-28 사용자 요청 구현. 원본 InGame 씬의 기존 방과 연결 통로는 보존하고, StorybookLightPuzzle.Awake에서 Resources/ShadowDuet.prefab을 극장에 배치한다. 기존 토끼 윤곽은 왼쪽, 새 여우 윤곽은 오른쪽에 놓는다.

## 변경
- 네 오림: 토끼 몸통/귀 + 여우 몸통/꼬리. 받침·기둥·문양 전체를 잡는 콜라이더.
- 좌클릭 유지, 마우스 좌우는 카메라 기준 수평 이동, 휠은 수평 앞뒤 이동. 수직 시선과 WASD만으로는 물체 위치가 변하지 않는다.
- 가까운 거리/먼 거리에서 이동 감속, Shift 추가 정밀 조절. 우클릭은 귀/꼬리 뒤집기. 놓으면 고정, ESC는 안전하게 놓기.
- 세 투사등: 실제 위치 x=-4,0,+4. 한 개만 켜지고 켜진 렌즈는 금빛이다. 클릭/F 상호작용.
- 여우의 두 메시를 실제 비평면 종이로 제작. 왼쪽 광원에서 원하는 그림자로 역투영한 외곽을 사용해 다른 광원에서는 그림자가 왜곡된다. 별도 검은 가짜 그림자를 벽에 붙이지 않는다.
- 동물마다 1.25초 유지 후 독립 기록. 기록된 오림은 고정되고 그림자 캐스팅을 종료해 다음 동물을 가리지 않는다. 두 기록 모두 완료해야 원래 P2와 문/스토리가 진행된다.
- 기존 장지·코럴·청록 재질을 사용한 재사용 메시/프리팹. 새 광원과 모델은 Room 가시성을 따른다.

## 검증
Unity 6000.3.10f1 격리 프로젝트의 실제 InGame 씬에서 두 차례 검증. 최종 play-check.txt 참조.
- 네 물체 각각 받침/기둥/오림을 조준하고 실제 좌클릭으로 잡기.
- 위보기 안정성, 좌우 이동, 휠 거리 조절, WASD 유지, 놓기, 근거리/원거리 감속.
- ESC 해제, 범위 밖 거부, 실제 F 입력으로 투사등 선택.
- 토끼 단독으로는 미완료, 잘못된 광원에서 여우 거부, 좌우 위치를 보정해도 잘못된 광원은 실패.
- 두 동물 완성, 기존 P2 해결 전달, 숨겨진 방의 새 광원/아트 비활성화.
- 실제 카메라 렌더 wrong-light.png / fox-aligned.png 육안 확인. fox-aligned는 토끼 기록 이후 여우를 맞추는 순간이다.
- 프리팹의 모든 GUID 의존성이 원본 Assets 및 URP 패키지에 존재함을 검사했다.

최신 설계는 ../../24_그림자공방과_전방_난이도설계.md에 정리되어 있다. 자동 테스트는 조작과 기하 판정을 검증하며, 사람이 느끼는 난이도/재미 평가는 별도 플레이테스트가 필요하다.
