# F0 개별 소품 6종

2026-09-27. InGame 씬에 실제 메시와 재질로 배치했다. 각 모델은 `Assets/_BookTower/Generated/F0CraftedProps`의 개별 폴더 안에 독립 프리팹으로 저장된다. 생성형 콘셉트 이미지가 아니라 Unity 모델 렌더를 함께 제공한다.

| 모델 | 세부 요소 | F0 배치 |
|---|---|---|
| 01_BindingWorkbench | 둥근 모서리의 가죽 상판, 종이 단면, 서랍 3개, 손잡이, 보강판과 리벳, 가장자리 실밥 | 왼쪽 작업 구역 |
| 02_OpenClueBook | 양쪽 8겹의 휘어진 종이, 가죽 표지, 제본 끈, 책갈피, 다리와 빛을 암시하는 도해, 독서대 | 작업대 위 |
| 03_InkwellAndQuill | 둥근 잉크병, 금속 입구, 라벨, 접힌 종이 깃펜과 깃결 | 책 오른쪽 |
| 04_PaperLantern | 육각 종이면, 얇은 잎 압인, 테두리, 고리와 받침, 작은 조명 | 책 왼쪽 |
| 05_BoundBookStack | 서로 다른 크기와 회전의 책 4권, 불규칙한 종이 단면, 잠금 띠 | 작업대 옆 바닥 |

`01_*.png`부터 `06_*.png`까지는 개별 모델 확인용 렌더이며, `player-workbench.png`는 Play Mode의 실제 플레이어 카메라다. 미리보기에는 모델 형태를 보기 위한 별도 조명이 사용되었다.

이번 단계는 모델링과 씬 배치다. 책 읽기, 수레 이동, 서랍 열기 등 새로운 상호작용은 구현하지 않았다. 도해는 환경 표현이며, 최신 설계 문서의 배치형 퍼즐이 구현되었다는 의미가 아니다.

## 검증 및 재생성

- `asset-checks.txt`: 여섯 프리팹의 메시·재질 누락 여부, 삼각형 수, 렌더러 수와 바운드 기록.
- `../InteriorRoomsV3/F0-play-verification.txt`: 기존 광선·다리·문·1A 연결 이동 검증.
- 메뉴 `Book Tower/F0 개별 공예 소품 제작`: InGame을 열고 플레이를 종료한 상태에서 실행. 기존 생성 장식의 단순 작업대·선반을 제거하고 새 소품 루트를 생성한다. 이후 F0 조명 패스를 재적용한다.
- 구현 파일: `Assets/_BookTower/Editor/F0CraftedPropsBuilder.cs`.

레퍼런스의 구성 요소와 종이·제본 테마를 모델로 옮긴 단계이며, 사진의 미세한 마모와 모든 형상을 동일하게 복원한 것은 아니다. 성능 프로파일링 및 LOD 제작은 이번 검증에 포함되지 않는다.
