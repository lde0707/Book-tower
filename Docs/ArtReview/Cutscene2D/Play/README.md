# 2D 컷신 Play 캡처

- 01: 첫 만남. 3D 카메라가 아닌 화면 전체 종이 그림.
- 02: 새가 정령에게 빛을 건네는 중간 프레임.
- 03: 동행 약속. 큰 글자 설정에서 대화창 판독 확인.
- 04: M01 수선 기억. 중앙은 과거의 새, 양옆의 작은 캐릭터는 현재의 정령과 새.
- 05: 1A 그림자 방 입장.
- 06: M02 이름 ‘모아’ 등장.
- 07: 마지막 대사 후 3인칭 플레이 복귀.

자동 입력 검사로 기본 F와 재지정 R의 누르기/유지/떼기, 전체 표시/다음 대사, 마지막 문장 종료, Esc/설정 복귀, 움직임 완화, 실제 이동 복귀를 확인한다. 검증은 플레이어 설정·기록과 별도 임시 저장소를 사용한다.

그림 레이어는 고정 원화의 위치·회전·크기·투명도를 움직인다. 애니메이션 프레임을 새로 그린 영상은 아니다. 실제 화면 UI처럼 배경과 캐릭터 원색을 유지하도록 캡처 시 3D 후처리를 끈다.
