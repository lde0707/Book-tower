# 종이 정령 — 부드러운 애니메이션

| 클립 | 프레임 | 길이 | 반복 |
|---|---:|---:|---|
| Idle | 72 | 1.20초 | 켜짐 |
| Move | 48 | 0.80초 | 켜짐 |
| Jump | 44 | 약 0.73초 | 꺼짐 |

60fps로 생성한 키 사이를 연속 곡선으로 보간한다. Idle/Move의 처음과 끝 값 및 기울기가 일치해 루프 경계에서 멈칫하지 않는다. 마지막 경계 키는 프레임 수에 포함하지 않는다.

지상/착지 전환은 0.14초, 점프 진입은 0.05초 블렌딩이다. 실제 이동과 점프 궤적은 기존 PlayerController가 담당한다. GIF는 30fps 미리보기이며 Jump도 비교용으로 반복한다. 게임의 Jump 클립은 반복하지 않는다.

## 전환 검증 수정

기존 검사는 Animator.Update(0.12)를 두 번 호출했다. 첫 호출에서 전환이 시작되고 두 번째 호출에서 0.12초만 진행되어, 0.14초 전환의 85.7%에서 Move 전환 실패로 잘못 판정했다. 실제로 현재 상태 Idle, 다음 상태 Move, 전환 진행률 0.857을 재현했다.

검사를 60fps 18틱(0.3초)의 제한된 시뮬레이션으로 바꾸고, 전환 완료와 도착 상태를 모두 검사한다. 검증용 씬은 독립 PreviewScene으로 만들어 사용자의 열린 씬을 저장하거나 교체하지 않는다.

## 확인한 것

- Unity 6000.3.10f1 컴파일 및 배치 검증 종료 코드 0
- Idle → Move → Jump → Move → Idle → Jump → Idle 전환 통과
- 72/48/44 프레임, 모든 곡선의 유효한 보간 기울기, 루프 경계 값/기울기 일치
- 애니메이션이 게임플레이 루트 위치를 바꾸지 않음
- 164프레임 렌더 완료
- InGame 씬과 PaperSpirit 프리팹의 Animator가 갱신된 컨트롤러 GUID를 참조함
