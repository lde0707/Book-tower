# 정령 종이 주름과 걷기 보강

2026-10-02. 최신 V6 형태를 유지한 V7 수정이며, 캐릭터 디자인을 새로 바꾸는 작업은 아니다.

## 적용

- 모자의 촘촘하고 거친 요철을 최대 7mm 안에서 완화했다. 얇은 겹장도 표면을 따라가게 하고, 해진 경계와 그 안쪽 첫 정점 고리는 고정했다. 옷·목도리·소매의 변화 한도는 2.5mm다.
- 거친 균열 범프와 어두운 틈 착색을 줄였다. 섬유 노멀, 종이의 큰 접힘, 여러 겹의 윤곽은 남겼다.
- 실제 씬이 사용하는 ReleaseMaterials의 패딩된 정령 아틀라스까지 갱신했다. 원본 HoodPaper 텍스처만 바꾸고 게임 재질에는 반영되지 않는 문제를 피했다.
- Move의 다리 교대, 무릎 굽힘, 발 들기, 반대편 팔 흔들기, 몸통의 작은 좌우 체중 이동을 강화했다. 걷는 순간에만 옷단이 들리며 발이 보인다. 서 있을 때의 긴 옷 길이는 유지한다.
- 이동 속도 3.8, Shift 달리기 5.9, 점프 및 나머지 상태 전환은 유지했다. 23개 본, 10개 클립과 기존 FBX GUID를 유지했다.

## 확인 자료

- [Unity 걷기 루프 영상](walking.mp4): 실제 씬에서 Move 클립을 24개 시점으로 샘플링했다. 1.1초 루프이며 렌더 프레임을 진행시켜 GPU 스키닝 갱신 후 촬영했다. 컨트롤러로 이동하는 녹화 영상과는 구분한다.
- [클립·스킨·3개 방 렌더 검사](After/review.txt): 10개 클립의 유한한 변형, 정상 바운드, 재질 연결. 걷기에서 양발의 앞뒤 차이가 -0.4275~+0.4275m로 교대한다.
- [실제 키 입력 검사](Animation/play-check.txt): W, 양쪽 Shift, 감속, Space 점프·착지·효과음, 일시정지 통과.
- [F0](After/F0-play.png), [1A](After/1A-play.png), [1B](After/1B-play.png) 실제 게임 카메라 렌더.
- [메시·재질 수정 수치](mesh-material-check.json), [내보내기 검사](export-check.json).

기능 검사는 별도 Unity 검증 복사본에서 수행하고 검증된 FBX·텍스처·재질만 본 프로젝트로 옮겼다. 새 플레이어 빌드의 성능 측정과 초행 플레이 테스트는 이번 범위에서 수행하지 않았다. 걷는 도중 옷 아래 다리가 드러나는 정도와 보폭의 취향은 영상으로 추가 판단할 수 있다.

## 재생성

`Tools/refine_spirit_soft_paper.py`의 model → bake → rig 순서로 실행한다. 항상 원본 V6에서 시작해 스무딩이 누적되지 않는다. rig는 우선 `Logs/F0ArtValidation`에 내보낸다. 검증 후에만 런타임 에셋을 교체한다.
