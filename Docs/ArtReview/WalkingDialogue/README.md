# 통합된 새 자세와 이동 중 도입 대화

새의 분리 날개 회전을 없애고 몸과 날개를 함께 그린 기다림/빛 건네기 자세를 같은 위치에서 전환한다. 내장 image_gen으로 생성했다. 원본과 프롬프트는 이 폴더의 prompts.json 및 Assets/_BookTower/Art/Cutscenes/WholeBirdV1에 보관한다. offer는 제작 참고용, release는 빛 씨앗을 별도 이동시키기 위해 그림 안의 씨앗을 뺀 실제 재생용 자세다.

도입 대사는 16개에서 8개로 축약했다.

1. 종이새: 저기… 들려?
2. 종이새: 빛이 거의 꺼졌네. 잠깐만… 내가 도와줄게.
3. 종이새: 내 빛을 조금 나눠 줄게. 눈을 뜰 수 있으면 좋겠다.
4. 나: 따뜻해… 고마워. 여긴 어디지?
5. 종이새: 책 속의 작업방이야. 길이 접히면서 갇혔어. 마지막 장에 내 집이 있는데… 돌아갈 수가 없어.
6. 나: 나는 아무것도 기억이 안 나. 그런데 네 날개… 나한테 빛을 줘서 흐려진 거야?
7. 종이새: 조금 쉬면 괜찮아. 저 작업책에 길을 잇는 그림이 있어. 함께 살펴봐 줄래?
8. 나: 응. 이번엔 내가 도울게. 네 집까지 같이 가자.

1~3은 정령의 1인칭 컷씬이다. 빛 전달 전에는 무대의 새와 정령 손을 모두 숨기고 대화창에서 새의 검은 실루엣만 보여 준다. 세 번째 대사에서 빛이 카메라 쪽으로 커지며 다가온다. 3.8초에 새와 초상이 드러나고, 새가 완전히 드러난 뒤 3초를 유지하면(전달 시작 약 7.45초) 네 번째 깨어남 대사로 자동 전환한다. 이것은 도입의 단일 연출 전환이며 다른 대사는 자동으로 넘어가지 않는다. 도착 전 클릭은 빛 전달을 건너뛰지 않는다.

4번째 대사가 시작되면 컷씬을 닫고 카메라와 동행 새를 플레이 상태로 돌린다. 하단 대화창에는 현재 말하는 정령/새 초상이 함께 나온다. 짧은 동행 대사에도 초상을 추가했다. 이동/점프/마우스 시점 조작을 허용한다. F/좌클릭은 대사의 전체 표시와 다음 대사로 사용하고 해당 입력이 월드 상호작용에도 전달되지 않게 한다. ESC는 이동과 대사를 멈추고, 재개하면 이동 중 대화로 돌아온다. 마지막 대사 후에는 일반 상호작용이 복구된다.

F0 완료/1A 기억 컷씬은 기존 방식이다. Play 검증 결과는 play-check.txt에 기록한다.
