# 레퍼런스 검토 기록
2026-09-25 · built-in image_gen 사용

## 선택 결과
16개 공간, 3A 재방문을 포함한 17개 상태 보드와 왜상 면 분할 보조 연구 1장. 갤러리는 selected-images.json의 최종본을 사용한다. 초기본과 수정본은 삭제하지 않았다.
모든 생성 결과를 시각적으로 검토했다. 2D/2F의 잘못된 다른 방 표기를 수정했고, 3C의 서쪽/수직 광로를 남쪽으로 되돌아가는 광로로 수정했다. 3A 재방문은 공간 분위기 보드와 국소 면 분할 연구를 분리했다.

## 모델러가 이미지 그대로 복사하면 안 되는 부분
- 이미지 평면도와 C0/C1/C2 표식은 개념도다. 정확한 진입 방향, 좌표, 카메라 투영은 camera-layout.json과 interaction-layout.json을 따른다. 생성된 눈금과 그림 속 정령 크기는 정밀한 축척 검증을 거치지 않았다.
- 몇 보드는 종이가 석재 균열처럼 보이고 축/고리가 금속처럼 보인다. 실제 모델은 섬유 노멀, 얇은 종이 적층 단면, 말린 종이 축으로 제작한다. 황갈색 조명을 그대로 베이크하지 않는다.
- 1A 보드는 차광 날개/관측대 구조 참고다. 목표판의 비대칭 홈과 실제 그림자 결합은 상세 모델 단계에서 별도 제작한다. 이 이미지만으로 HUD 없는 목표 인지가 검증되었다고 볼 수 없다.
- 1B 검은 다리의 폭/끝 위치는 실제 태양 광선과 접이판의 투영으로 계산한다. 이미지의 검은 길을 임의 충돌판으로 복사하지 않는다.
- 1C/3B 광로는 논리 광선 스케치다. 실제 각 반사면의 법선과 입사/반사 방향을 구현에서 맞춘다. 3B의 역광 관통 축은 낮은 퍼즐 광로와 별도로 높이/개구부를 예약한다.
- 2B 종이 관객 장식은 정령/간단한 종이 모양으로 바꾸고 인간 군중으로 읽히지 않게 한다.
- 3A의 최초 보드에는 천장 면이 충분히 드러나지 않는다. 재방문 보드의 곡면 띠를 동일한 자산으로 처음부터 배치하고 상태만 바꾼다. 방문 사이 방이 새로 생겨서는 안 된다.
- 3A-RETURN 공간 보드의 그림은 아직 한 형상으로 정확히 정렬되지 않는다. 이를 완성된 P15 정답 이미지로 쓰지 않는다. 추가 면 분할 연구는 세 면에 분배하는 원리를 설명하며, 그 사각 국소 방을 전체 3A 구조로 대체하지 않는다.
- 왜상은 12개 실제 면의 월드 정점 투영으로 제작한다. 머리를 천장에 두는 보조 연구는 보이는 앞면과 법선에 따라 성립하지 않을 수 있다. 기존 바닥/벽/천장 분할 방식으로 실제 카메라에서 보이는 면을 선택하고 메시를 역투영한다. 그림을 텍스처로 그대로 붙이는 방식은 사용하지 않는다.
- 3C 남향 역광 방향은 수정했지만 3A와의 고도/직선 연결은 배치 검증 전이다. 광선이 문틀이나 접지판에 막히지 않도록 월드 배치에서 확인한다.
- HD 보드는 세 크기 책 공간을 펼쳐 보여주는 표현이다. 실제 연결은 세 개 셀과 문 전환으로 만들며 서로 다른 규모의 같은 표식을 대응한다.

## 현재 Unity 상태
이번 변경은 Docs 아래 설계/이미지 산출물이다. 새 거대 방, 새 퍼즐, 새 오디오를 씬에 적용한 상태가 아니다.
앞선 겹침 수정 빌드와 자동 표면 후보 검사는 완료했으나 최종 화면 검수는 아직 남았다. 추가 문/다리 회귀 실행은 2026-09-25 Unity 편집기가 이미 열려 있는 상태에서 배치 프로세스가 종료 코드 1로 끝나 실행되지 않았다. 사용 중인 편집기를 강제 종료하지 않았다. 과거 통과 보고서는 이번 수정 후 새 통과 결과로 취급하지 않는다.
