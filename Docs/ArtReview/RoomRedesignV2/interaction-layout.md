# 상호작용 그래프와 구역 좌표

좌표는 방 중심 기준 제안값이다. 8u 반경의 작업 구역을 먼저 만들고 방별 외곽/접기 운동에 맞게 연결한다. 억지로 모든 방을 같은 5개 섬 형태로 만들지 않는다. completionRule은 구현 전 논리 명세이며 현재 코드의 변수 이름이 아니다.
