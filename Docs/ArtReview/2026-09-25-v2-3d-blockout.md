# V2 실제 3D 맵 적용 기록 (2026-09-25)

## 적용 기준
- 플레이어: 높이 1.40u, 지름 0.60u
- 이동 속도: 5.5u/s
- 점프 높이: 1.20u, 이론상 최대 수평 이동 약 4.02u
- 주 동선 폭: 5.50u
- 방 크기: 56×44u ~ 92×84u
- 방 횡단 시간: 약 10.2초 ~ 16.7초
- 내부 단차: 최대 4.5u, 경사/연결 길로 접근

## 실제 씬 변경
- 16개 방을 직사각형 바닥 대신 5개의 비정형 종이 구역과 연결 동선으로 블록아웃했다.
- 각 방은 서로 다른 순환, 교차, 왕복 동선을 사용한다.
- 기존 FoldPanel, CollectiblePiece, EchoCrease에는 받침과 접근 길을 생성해 퍼즐 기능을 보존했다.
- 방 사이 다리는 폭 5.5u로 통일하고 양 끝에 종이 접합부를 추가했다.
- 잠긴 출구는 세워진 페이지와 접힌 다리로 막고, 해결 시 페이지와 다리가 함께 열린다.
- 3A→3B→3C는 P15 광축을 위해 +Z 직선으로 정렬했다.
- 실제 높이 1.4u 정령 축척 오브젝트를 각 방 V2_블록아웃 아래에 비활성 상태로 넣었다.

## 검증 상태
- 레이아웃 정적 검사: 오류 0건. 긴 전이 다리 5개는 의도한 거대 스케일 경고로 남아 있다.
- 표면 겹침 감사 보고서는 `Docs/ArtReview/Overlap/before.txt`에 생성했다.
- 출구 잠김 검증에서 전 잠금 구간의 중앙/가장자리 차단을 확인했다.
- 열린 다리 자동 왕복은 F0→1A, 1A→1B를 통과했으며 1B→1C 남쪽 벽의 문 절개를 추가한 뒤 씬을 재빌드했다.
- 기존 방향 검증기는 확대 전 좌표로 1A의 F키 대상을 찾고 있어 V2 좌표 대응이 별도 필요하다.

## 남은 제작 범위
현재 결과는 플레이 가능한 3D 블록아웃과 기존 퍼즐 보존 단계다. 레퍼런스에서 제안한 신규 다단 퍼즐, 개별 미니게임, 방별 전용 사운드와 최종 아트 모델은 후속 제작 범위다.
