# 1B 기억등 — 조작 상태와 놓는 자리 개선

2026-09-28. 기존 P3 진행 조건을 유지하면서 등불과 받침의 시각·입력 위치를 수정했다.

- 운반용 기억등: 곡면 종이 패널 6장, 굽은 등살, 접힌 지붕, 감싼 손잡이, 앞쪽 독립 걸쇠 2개. 종이 섬유 컬러·노멀을 사용한다.
- 잠김: 금속 혀가 어두운 수납 홈에 맞물린다. 열림: 걸쇠가 바깥으로 65도 들리며 홈이 드러난다. 조준 문구는 현재 상태와 다음 동작을 구분한다.
- 빛 담기 → 양쪽 잠그기 → 들기 → 받침에 놓기 → 양쪽 걸쇠 열기로 정리했다. 한쪽만 잠근 상태로는 운반하지 못한다. 운반 중에는 열 수 없고, 받침에 놓은 뒤 한쪽만 열어도 빛은 보존된다. 두 번째 걸쇠를 열 때 기록/출구 장치가 반응한다. 공중에 들고 있는 등불의 고리를 다시 조준해야 했던 불편을 없앴다.
- 네 받침의 조작 콜라이더와 실제 등불 배치 좌표를 일치시켰다. 등 밑의 돌기와 받침 홈, 안쪽 원형 자국을 대응시켰다. 햇빛/책/문 문양으로 충전/점검/출구의 용도를 구분한다.
- 점검대 표식은 실제 접근 방향을 향한다. 충전대 앞을 가리던 장식 책더미 두 묶음은 옆으로 옮겼다.
- 붉은 벽걸이: built-in image_gen으로 724×2172(1:3) 세로 구도를 새로 제작했다. 까마귀는 자연 비율로 두고, 긴 부분은 초승달·덩굴·등불 문양으로 채웠다. 정사각형 러너/의자/선반 문양은 기존 재질을 유지한다.

## 적용

`ReadingLanternPresentation.Apply`가 기존 퍼즐의 연결을 유지한 채 Resources의 모델·받침을 부착한다. 에디터에서 열려 있는 InGame에 미저장 변경이 있으면 저장을 강제하지 않는다. Play의 Awake에서도 한 번만 보완한다. 방을 통째로 재생성하거나 사용자의 원본 씬을 검증용 씬으로 덮어쓰지 않는다.

## 검증

`structure.txt`: 네 받침 좌표와 모델 참조 검사.
`play-check.txt`: 실제 F/마우스 입력, 열린/잠긴 걸쇠 각도와 문구, 운반 제한, 점검대 배치, 창 고정 전 재충전 거부, 출구 우선 실패, 최종 문 개방, CharacterController 통로 이동.
테스트는 별도 Unity 검증 프로젝트에서 수행한다. 사람의 첫 플레이 이해도 검증을 대신하지 않는다.
