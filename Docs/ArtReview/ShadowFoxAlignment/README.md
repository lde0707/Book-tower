# 1A 여우 그림자 정렬 판정 수정

2026-10-02. 왼쪽 조명에서 그림자가 윤곽과 겹쳐 보여도 해결되지 않는다는 보고에 대한 수정이다. 방·모델·목표 윤곽·조명 위치는 변경하지 않았다.

## 재현과 원인

기존 검사는 제작 시 정한 정확한 좌표에서만 성공 여부를 확인했다. 실제 조작을 흉내 내 몸통을 정답에서 x +0.06 / z +0.02, 꼬리를 x -0.04 / z -0.02만큼 이동시키면 [화면상 거의 일치](near-match-before.png)하지만 실패했다. 스크린 투영의 최대 오차가 몸통 0.10200, 꼬리 0.09651이며, 기존 조건은 각각 0.10 미만이었다. 어느 외곽점 하나만 경계를 조금 넘어도 전체가 무효였다. 이 재현 배치는 사용자의 저장 좌표를 읽은 것이 아니라 같은 증상을 확인하기 위한 근접 배치다.

또한 잡고 있는 동안에는 1.25초 기록 타이머가 진행하지 않았다. 이 규칙은 유지하되, 정렬됐는지와 놓아야 하는지를 알려 주지 않던 부분을 보완했다.

## 적용한 판정

- 선택한 실제 광원과 오림의 변환을 이용하는 기존 기하 투영을 유지한다.
- 두 부품 각각 전체 점의 RMS 오차 ≤ 0.14, 최대 오차 ≤ 0.22를 모두 만족해야 한다. 한 점의 미세한 초과에 실패하지 않으면서 전체 형태가 어긋난 경우는 막는다. 단위는 무대 스크린 좌표의 미터다.
- 꼬리 방향, 점등, 두 부품 정렬, 손을 놓은 뒤 안정된 상태에서 1.25초 유지하는 조건은 유지한다.
- 정렬 시 잡고 있다면 `여우 그림자가 맞았다 · 마우스를 놓으면 책장에 기록된다.`를 표시한다. 놓은 상태라면 잠시 유지하라는 안내를 표시한다.
- 누락·비정상 윤곽 데이터는 성공으로 처리하지 않는다.

## 검증

- [수정 전 재현](before.txt), [수정 후 실제 클릭·놓기 검사](after.txt).
- 정확한 정답 및 위 근접 배치 성공. 꺼진 조명, 반대로 뒤집힌 꼬리, 어긋난 몸통, 잘못된 꼬리 크기는 실패.
- 중앙·오른쪽 광원에서 옆 위치를 보정해도 접힌 외곽이 맞지 않으면 실패.
- 실제 마우스로 잡기 → 정렬 안내 → 놓기 → 여우 기록 성공. 여우 먼저, 토끼 나중 순서로도 기존 P2 완료 이벤트까지 전달됨.
- [기존 1A 통합 검사](duet-regression.txt): 네 물체의 조작·WASD·토끼 먼저/여우 나중·등 선택·기록·방 가시성 회귀 통과.
- [기록된 여우 화면](fox-recorded.png). 새 타겟 이미지를 붙여 해결한 것이 아니며 실제 그림자와 판정 코드의 허용 범위를 조정했다.

검증은 현재 InGame 씬과 같은 에셋을 사용하는 별도 Unity 복사본에서 수행했다. 사용자 플레이 상황 자체를 녹화해 검사한 것은 아니며, 새 빌드 성능 측정과 초행 난이도 평가는 이번 범위에서 수행하지 않았다.
