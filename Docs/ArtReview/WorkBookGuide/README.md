# 처음 읽는 작업책의 시각적 안내

- 도입이 끝나면 상단 목표를 ‘먼저 왼쪽 작업대의 황금빛 책 살펴보기’로 표시한다.
- 실제 작업책 위에 따뜻한 국소 조명을 켜고, 펼친 페이지를 약 1.3도 범위로 천천히 움직인다. 움직임 줄이기 설정에서는 정지된 빛과 페이지를 유지한다.
- ‘제본사의 작업책’ 종이 표찰을 책 위 화면 좌표에 붙인다. 책이 시야 밖이면 화면 가장자리에서 방향을 표시한다. 사거리 안에서는 현재 지정된 상호작용 키와 좌클릭 읽기 안내를 표시한다.
- 첫 걸음의 새 대사도 ‘왼쪽 작업대야. 빛이 머무는 펼쳐진 책, 보여?’로 맞춘다. 카메라를 강제로 돌리지 않는다.
- 읽는 즉시 표찰·조명 강조를 끄고 페이지를 원래 각도로 복원한다. F0 퍼즐을 먼저 완료한 경우에도 안내를 해제한다. 다른 방·메뉴·전체 화면 컷씬에는 표찰을 표시하지 않는다.
- 기존 F/좌클릭 읽기, 책상 상판의 읽기 연결, 목표 갱신은 유지한다. 씬 교체 없이 런타임에서 적용한다.

Unity Play 검증: 83개 PASS 행. 실제 작업책 연결, 읽기 전 표찰·조명 표시, 읽은 뒤 안내 해제, F/좌클릭 읽기 및 F0–1A 진행 통과. 최종 원본/검증본 변경 코드 해시 일치.
