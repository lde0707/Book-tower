# 1A → 1B 입구 회랑 보수

2026-09-28. 검사 범위는 두 번째 방을 나오는 경사로 끝, 꺾이는 연결 회랑, 세 번째 방의 입구다.

## 원인과 수정

- 기존 대각선 통로가 정면 문틀에 비스듬히 겹쳤다. 바닥과 옆면 사이에는 외부 배경이 보이는 틈도 있었다.
- 통로 끝을 문틀 정면 방향으로 돌리는 단면 여섯 개로 바닥·벽·아치 천장을 연결했다. 기존 문 구멍의 폭 7m에 맞추고, 방 안쪽까지 연결 면을 연장했다.
- 바닥 높이를 종이 바닥 장식보다 높여 겹친 표면 깜빡임을 피했다. 시각 메시의 중복 뒷면 삼각형을 제거하고 양면 충돌 메시와 분리했다.
- 새 회랑과 겹치던 이전 대각선 구조·장식 구간을 비활성화했다. 경사로 벽이 도착 지점을 지나 길게 돌출돼 역방향 우측 이동을 막던 부분은 끝에서 3.5m 줄였다. 시작 쪽 끝은 그대로 유지한다.
- 남색 종이 벽, 크림색 아치 천장, 붉은 책갈피 러너가 방 입구까지 이어진다. 기존 1A·1B 퍼즐은 변경하지 않았다.

## 반복 검증

1. 수정 전 4개 시점 렌더와 주변 충돌체 목록으로 입구 차폐 및 바닥 노출 확인.
2. 구조 검사: 5개 구간 × 15개 지점 × 3개 횡방향 위치 × 위/아래/좌/우 = 900개 검사선.
3. 실제 CharacterController로 중앙 및 좌우 1.5m 경로를 각각 양방향 이동. 첫 검사에서 우측 역방향 걸림 발견 후 돌출 벽을 줄여 재검증.
4. 3개 관찰 지점에서 4방향씩 총 12개 카메라 렌더. 외부 배경을 자홍색으로 지정하고 노출 픽셀을 계산.
5. 새 회랑과 기존 장식 루트를 임시로 제거한 씬에서 Play 시작. 런타임 적용, 중복 생성 여부, 이전 벽 재등장 여부, 이동 및 12방향 노출 검사를 반복한다.

수치 결과는 `structure.txt`, `play-check-round2.txt`, `play-check.txt`에 저장한다. 제한된 검사 위치의 결과이며 게임 전체의 모든 방·모든 카메라 위치를 검증한 것은 아니다.

## 원본 적용

Resources의 `ReadingEntrancePassage.prefab`과 `ReadingEntrancePassage.Ensure()`가 적용한다. 에디터는 미저장 씬을 강제 저장하지 않고, 런타임에서도 새로 시작할 때 적용한다. 검증용 씬으로 원본 씬을 덮어쓰지 않는다.
