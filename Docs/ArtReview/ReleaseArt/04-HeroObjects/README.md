# 04 주요 오브젝트

F0 작업책에 접힌 책갈피와 작은 종이 끝 움직임을 더했다. 기존 목표 안내·읽기·문 전체 연출은 유지하고 회귀 검사했다.

1A는 완성한 토끼/여우 오림을 무대 옆으로 옮긴다. 기록된 그림자는 남고 다음 동물의 광로를 가리지 않는다. 토끼→여우, 여우→토끼 두 순서를 확인했다. 투사기 광량과 하단 쿠키도 조정했다.

1B는 기억등의 두 고리·기록대·손잡이·창·출구 상태와 실제 조작을 다시 검사했다. 이번 단계에서 새 퍼즐 해법을 추가하지 않았다.
