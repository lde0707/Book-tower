# 06 큰 형태와 공간 구성

F0는 후면의 높이가 다른 제본 표지, 1A는 겹장 극장 아치·측면 프레임·휘어진 천장 띠, 1B는 남색 둥근 천장 리브·서가 아치·압인 부조를 추가했다. 퍼즐 광로와 이동 공간은 비워 두었다.

새 메시 128개를 만들고 새 정적 장식은 공간별 30개 그룹으로 병합했다. 기존 방 전체를 비정형 구조로 재건축한 것은 아니다. 1A의 넓은 바닥과 반복 천장, 1B의 반복 서가는 개별 소품 조형의 후속 개선점으로 기록했다.
