# 05 카메라와 가독성

`PaperCamera`는 충돌 시 즉시 당겨지고 장애물에서 벗어나면 지수 보간으로 복귀한다. SphereCast의 최근접 거리보다 밖으로 보간하지 않는다. 그림자 물체를 잡을 때 자동 회전과 흔들림을 억제한다.

맵 기준 Q/E 90도 방향, 이동 시 잠금 해제, 마우스 조준·WASD 드래그, 문 연출과 대사 뒤 입력 복귀를 검사했다. 월드 네 방향·세 화면비와 실제 빌드의 ESC/설정 UI를 캡처했다. OS가 2100px 창을 1920px로 제한했으므로 21:9 Overlay UI 검증이라고 주장하지 않는다.
