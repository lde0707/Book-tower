# 완성 아트 02 — 종이 재질 적용 기록

작업일: 2026-10-02. Unity 6000.3.10f1 / URP 17.3. 기준 씬: `Assets/Scenes/InGame.unity`.

## 적용 범위와 결과

F0·1A 및 해당 방에 속한 연결부, 정령과 모아의 공통 재질을 수정했다. 57개 원본 재질에서 UV 크기별 99개 변형을 만들고 렌더러 3,268개에 적용했다. 검사 범위의 머티리얼 슬롯은 전후 3,367개로 같다. 머티리얼 종류가 늘었으므로 슬롯 수가 같다는 사실을 드로 콜이나 GPU 비용이 같다는 뜻으로 해석하지 않는다.

- **장지**: 기존 `MulberryFiber`의 섬유 색을 남기고 색·얼룩과 독립적으로 만든 얕은 높이 정보로 노멀을 교체했다. 바닥 전체가 돌처럼 거칠게 보이는 반응을 줄였다.
- **염색 표지**: 버건디·청록 등 원래 색을 유지하고 장지보다 차분한 압인과 낮은 광택을 적용했다.
- **속지 단면**: 얇은 층 결과 낮은 광택을 사용한다. 실제 층과 두께는 기존 메시가 담당한다.
- **면실**: 종이 얼룩을 제거하고 방향성 결을 사용한다. 굵은 꼬임은 기존 밧줄 메시가 담당한다.
- **황동**: 금속 영역과 산화 영역의 반사 반응을 분리했다. **은박**은 이번 맵에서 노출 금속으로 처리한다.
- **정령·모아**: 노멀 강도를 각각 0.75→0.12, 0.45→0.20으로 낮추고 텍스처 조각 바깥의 검은 여백을 확장 색으로 채웠다. 얼굴·모자·겹옷의 원래 그림과 실루엣, 애니메이션 리그는 유지했다.

씬 외에 런타임 재생성용 `FoyerPassageCeiling.prefab`, `HoodSpirit.prefab`, `MoaSculpt.prefab`도 같은 재질로 연결한다. 발광체·광선·광학 전용 셰이더와 고유 문양 아틀라스는 보존한다. 1A 벽화는 색과 UV를 보존하면서 노멀만 약하게 조정한다.

## 채널과 표면 기준

URP/Lit의 `_BaseMap`은 sRGB 색, `_BumpMap`은 Normal Map 타입, `_MetallicGlossMap`은 선형 데이터다. 새 노멀은 별도 높이 정보에서 만들며 Unity의 색→노멀 자동 변환을 사용하지 않는다. 금속 맵 **R = Metallic, A = Smoothness**, G=1·B=0은 현재 셰이더에서 사용하지 않는다. 별도 AO 맵은 만들지 않았다.

| 재료 | 새 노멀 강도 | Smoothness 실측 범위 | Metallic |
|---|---:|---:|---|
| 장지 | 0.8 | 0.094–0.141 | 0 |
| 염색 표지 | 0.8 | 0.169–0.263 | 0 |
| 속지 단면 | 0.8 | 0.067–0.114 | 0 |
| 면실 | 0.8 | 0.067–0.114 | 0 |
| 황동 | 0.55 | 0.200–0.443 | 노출 금속 1 / 산화 0 |
| 은박 | 0.7 | 0.569–0.659 | 1 |

노멀 강도 숫자는 서로 다른 원본 노멀 사이에서 직접 비교할 수 없다. 새 장지 노멀은 원래 거친 색 변환 노멀보다 변화량 자체가 작다. 황동 산화 영역은 약 17.30%다. 은박의 현재 데이터에는 먼지 영역이 없으며, 황동과 달리 모든 픽셀이 금속이다.

환경 재료는 1,024², 캐릭터 아틀라스는 기존 2,048² 크기를 유지했다. 밉맵·Trilinear·이방성 필터 8·고품질 압축을 사용한다. 24개 생성 맵 중 `Paper_Color.png`는 비교 실험용으로 남았으며 최종 장지 재질은 기존 섬유 색 이미지를 참조한다.

정령은 3,082,447개, 모아는 1,618,476개의 미사용 검은 픽셀을 인접 조각의 색·노멀·광택으로 확장했다. 원래 색이 그려진 영역은 각각 1,111,857개 / 2,575,828개 픽셀로, 세 채널 묶음 모두 원본과 바이트 단위로 일치한다. UV 자체를 다시 펼친 작업은 아니다. [데이터 검증](data-checks.txt).

## UV와 크기

반복 재질은 메시 삼각형의 UV 면적과 월드 면적 비율을 표본 측정하고 약 2u에 한 타일이 오도록 조절했다. 재질 수가 불필요하게 늘지 않도록 2의 거듭제곱 타일링을 사용한다. 제한에 걸리지 않는 1K 재질의 목표는 약 512texel/u, 양자화 범위는 대략 362–724texel/u다.

고유 문양·캐릭터 아틀라스는 타일링하지 않는다. 읽을 수 없는 메시와 LineRenderer는 측정값 0으로 기록하고 기존 기준 타일링을 사용한다. 면적 평균은 한 축으로 늘어난 UV를 고치지 못하므로 **모든 오브젝트의 섬유 크기가 완전히 같아졌다고 판단하지 않는다**. 캐릭터의 얼굴·옷 끝 전용 UV 개선과 극단적으로 늘어난 소품은 주요 소품 단계에서 별도 검사한다.

1번에서 만든 바닥·천장 패널의 두께와 겹침, 기존 모자·소매·옷자락 구조는 유지했다. 신규 실루엣이나 접힘 메시를 추가한 단계는 아니다.

## 비용과 검증

참조 텍스처의 에디터 런타임 메모리 합계는 111,164,838→144,031,836바이트, **+31.34MiB / +29.57%**다. 이는 `Profiler.GetRuntimeMemorySizeLong` 집계이며 독립 실행 파일의 정확한 GPU 메모리나 프레임 성능 측정값이 아니다. [전](memory-before.txt) / [후](memory-after.txt).

- [실제 재질 목록 전](Before/materials.csv) / [후](After/materials.csv), [UV 면적 밀도](After/density.csv).
- [적용 계약 검사](apply.txt): 렌더러 Transform·그림자 설정, 콜라이더 상태·경계, 광원 Transform·색·광량·그림자, 슬롯 수가 동일하다.
- 24개 맵의 색 공간·밉맵·필터·노멀 가져오기와 누락/오류 재질 검사 PASS.
- [F0 동작 검사](f0-play-checks.txt): F/마우스 상호작용, 오답 광선 경로, 광원 닫기·재개방, 다리 점유 보호, 추락 복귀, 출구 확정과 개방 후 재조작, 다리·문·다음 방 통로 이동 PASS.
- [1A 동작 검사](1a-play-checks.txt): 71개 검사와 최종 PASS. 오림 4개의 받침/기둥/문양 선택, 마우스 양축 이동, 플레이어 이동에 따른 드래그, ESC 해제, 거리 제한, 실제 F 광원 선택, 토끼 기록, 잘못된 광원의 여우 거부, 올바른 여우 그림자와 출구 연동을 확인했다.
- [적용 파일 해시](applied-sha256.txt): 검증 프로젝트와 실제 프로젝트의 씬·재질·텍스처·프리팹·검사 코드 376개 파일 SHA-256 일치. 적용 직전 본 프로젝트 씬이 최초 조사본과 같은지도 확인했고, 원본 씬과 프리팹 3개는 `Logs/ReleaseMaterialMainBackup-20261002-001832/`에 보관했다.
- 검사는 Unity Editor Play에서 수행했다. 이 단계에서 독립 실행 파일을 새로 빌드하거나 수동 플레이하지 않았다. 자동 실행 로그에는 Unity Editor Search 인덱스의 `ArgumentOutOfRangeException`이 있으나 프로젝트 코드의 컴파일 오류나 이번 검사 실패는 없었다. 이를 게임 코드가 경고 없이 깨끗하다는 증거로 사용하지 않는다.

새 재질만으로 레퍼런스 조명을 재현했다고 보지 않는다. 현재 장면에는 바닥·창 주변의 높은 밝기, 금속에 비치는 차가운 환경색, 일부 얇은 겹침의 강한 그림자가 남는다. 3번에서 노출·주광·반사 환경을 조정한 뒤 같은 지점에서 다시 비교한다. 정지 캡처만으로 움직일 때의 노멀 깜빡임이나 모든 카메라 방향을 검증했다고 주장하지 않는다.

## 재생성

- `ReleaseMaterialAudit.cs`: 실제 참조 재질·UV 밀도·슬롯 기록.
- `ReleasePaperMaps.cs`: 재료별 색/노멀/광택 데이터와 아틀라스 여백 생성.
- `ReleaseMaterialBuilder.cs`: 원본 GUID를 추적해 반복 실행 가능한 재질 연결. 원본 사본은 `Generated/ReleaseMaterials/Baseline`에 보관한다.
- `ReleaseMaterialReview.cs`: 적용·중성 견본·실제 카메라 촬영. `Run`은 적용과 촬영, `CaptureAfter`는 저장된 씬의 재촬영이다. 두 메서드는 자동검사용으로 종료 시 에디터를 닫으므로 작업 중인 에디터 대신 검증 프로젝트에서 실행한다.

전체 방을 다시 만드는 구형 생성기를 실행하면 재질 연결이 원복될 수 있다. 구조 생성 이후 이 단계의 재질 적용과 검증을 실행한다. 원본 재질을 삭제하거나 다른 방의 오래된 생성 코드를 일괄 수정하지 않았다.
