# F0·1A 외피와 열린 문 동선 보강

2026-09-26. Assets/Scenes/InGame.unity에 적용.

- F0 양쪽 문을 F0 실내 방향으로 170도 펼친다. 뒤쪽 회랑을 문짝이 가로막지 않는다.
- 문 너머 벽에 밝은 장지를 덧대고 오른쪽으로 이어지는 리본, 바닥의 끊어진 안내선, 통로 조명을 배치했다. 기존의 오른쪽으로 꺾이는 동선은 유지한다.
- F0 후면·동측 복도의 천장, 후면 서쪽 끝, 동측 복도 남벽, 출구 위 상부 외벽을 충돌면과 함께 추가했다.
- 1A 서쪽 입구의 상부·양옆 틈을 메우고 안쪽 천장 덮개를 추가했다.
- 1A 출구 윗벽을 넓혀 우측 벽과의 약 5cm 이음새도 닫았다.
- F0→1A 통로 양 끝에 벽과 천장이 겹치는 접합부를 추가하고 기존 곡면 천장에 MeshCollider를 붙였다.
- 두 아트 빌더에서 보강 패스를 호출하므로 방 모델을 재생성해도 보강이 다시 적용된다.

적용 도구: InteriorEnvelopeRepair.Apply. 기존 모델 계층 안의 ‘연속 외피 보강’과 통로의 ‘입구 겹침 덮개’만 교체하는 반복 실행 가능한 패스다. 구조 수정 전 씬 백업은 Logs/EnvelopeBackups에 있다.

[구조 검사](structure.txt)는 바닥·천장 표본 1,299쌍과 출입구를 제외한 외벽 2,670개 방향을 검사한다. 유한한 표본 검사이므로 모든 미세한 시각적 틈이 없음을 보증하지 않는다. F0→1A 양 끝은 덮개 보강과 실제 CharacterController 통과 검사로 확인한다. 1B 이후 방 외피는 이번 범위에 포함하지 않는다.
