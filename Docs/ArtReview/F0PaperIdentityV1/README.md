# F0 종이 재질 아트 시안 V1

작성일: 2026-09-27

사용자가 제공한 두 F0 레퍼런스, 기존 Unity Play 검증 캡처, 현재 InGame 씬의 카메라와 기믹 좌표를 바탕으로 제작한 네 방향 이미지다. **Unity에서 새로 렌더한 화면이나 재질 적용 결과가 아니라, 구현을 위한 AI 생성 아트 시안**이다. 원본 레퍼런스의 광택과 극세부를 줄이고, 근접 3인칭에서 읽히는 종이 재료와 기믹 구분을 목표로 했다.

## 이미지

| 방향 | 맵 기준 카메라 yaw | 화면의 중심 |
|---|---:|---|
| [정면](01-front.png) | 0° / 북쪽 +Z | 접이식 종이 다리, 천장 덮개와 반사판, 북쪽 출구 |
| [좌측](02-left.png) | 270° / 서쪽 -X | 단서 책 작업대, 조작 고리, 격자창 |
| [우측](03-right.png) | 90° / 동쪽 +X | 큰 밧줄, 격자창, 종이 더미, 광로의 측면 |
| [후면](04-rear.png) | 180° / 남쪽 -Z | 시작 공간, 닫힌 제본 벽, 작은 종이 아치 |

정령이 북쪽을 향한 채 카메라만 네 방향으로 전환하는 조건이다. 정면에서는 뒷모습, 좌우에서는 옆모습, 후면에서는 얼굴이 보인다. 네 장 모두 다리가 내려온 동일한 진행 상태를 의도했다.

## 현재 프로젝트를 반영한 기준

- 실제 InGame 씬: perspectiveFov 60, closeDistance 4.8, closeFocusHeight 1.85, pitch -2, shoulderOffset 0.55.
- 기준 정령 위치: (0, 3, -6). 이미지 구성용 관찰 지점이며 실제 시작 스폰 좌표를 뜻하지 않는다.
- F0 범위: x -16~16, z -20~16, 높은 실내 천장.
- 북쪽 출구만 존재한다. 후면의 큰 종이 패널은 출구가 아닌 벽이다.
- 높이 3의 양쪽 바닥 사이 z -1.2~7.2 공간을 폭 4.4의 종이 다리가 잇는다.
- 천장 광원 → 종이 덮개 → 입구 조절 은박 → 고정 방향전환 은박 → 건너편 조절 은박으로 이어지는 기존 기믹을 참고했다.
- 이미지의 부분 광로는 장식 종이꽃 쪽으로 향하고 출구 수광부는 아직 꺼진 상태를 의도했다.
- 이동식 거울이나 새로운 수레 퍼즐은 추가하지 않았다.
- 낮은 조작부에서 높은 장치로 이어지는 밧줄, 서쪽 작업대의 단서 책, 동서 창문, 책등 기둥을 주요 시각 표식으로 삼았다.

생성 이미지의 투시, 치수, 광선 연결 및 소품 위치는 근사치다. 코드의 충돌체, 반사 방향과 작동 조건을 바꾸는 설계도로 사용하지 않는다. 특히 후면의 벽 패널은 문처럼 보이지 않도록 실제 제작 시 연속된 가로 제본 틀로 구분해야 한다.

## 재질 방향

| 부위 | 목표 재료와 색 | 제작 시 주의 |
|---|---|---|
| 바닥 | 따뜻한 아이보리 장지 #E4D3AE, 두꺼운 종이 적층 | 넓은 얕은 접힘, 겹친 가장자리, 봉제선. 돌 타일처럼 깊게 갈라진 균열은 줄인다. |
| 벽 | 접은 종이 패널 + 먹색 제본 틀 #302D28 | 모서리와 겹침으로 두께를 표현하고 벽 전체의 고주파 노이즈는 낮춘다. |
| 책등 기둥 | 무광 적갈색 염색 종이 #823E2C | 반짝이는 가죽 표현을 피하고 잎 압인과 둥근 접힘을 살린다. |
| 반사판 | 차가운 은박/세이지 #A9B8AD | 방의 따뜻한 장식과 구분되는 주요 반사 재질. |
| 빛 | 부드러운 꿀빛 #F6D092 | 과도한 주황색 덧씌움을 줄이고 바닥 경계가 보이게 한다. |
| 밧줄·띠 | 면실 + 광택이 약한 오래된 황동 | 구조와 연결을 읽는 표식으로 사용한다. |

이번 결과의 일부 바닥·기둥 주름은 균열처럼 읽힌다. 실제 텍스처 제작 시 거미줄 모양의 균열을 그대로 복제하지 않고, 긴 접힘선과 드문 종이 섬유로 정리한다. 장식의 섬세함보다 플레이 거리에서 재료·조작부·이동 경계가 읽히는 것이 우선이다.
