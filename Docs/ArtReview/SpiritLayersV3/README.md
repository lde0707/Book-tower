# 정령 V3 — 감싸는 모자·종이 목도리·겹친 옷

타이틀 정령 레퍼런스를 바탕으로 실제 캐릭터 메시와 재질을 수정했다. 사진과 동일한 조명을 합성한 이미지가 아니라 Blender 메시 렌더와 Unity 실행 캡처로 확인한다.

## 변경

- V2보다 모자 앞부분을 조금 더 낮추고 양옆을 추가로 내려 얼굴을 감싸게 조형. 측면 폭도 줄여 머리 위에 뜬 우산처럼 보이는 느낌을 줄임.
- 얼굴에는 미세한 표면 굴곡·고운 펄프 결·옅은 색 변화. 눈과 기본 얼굴 비례 유지.
- 목에 실제 두께를 가진 종이 리본 세 겹, 뒤로 흐르는 끝 두 가닥 추가. 목도리 본체는 Body/Head, 끝은 기존 망토의 보조 동작에 연결.
- 다섯 망토 패널 위에 총 60개의 작은 종이층을 추가. 접점은 붙이고 가장자리를 띄워 실제 그림자 발생. 경계는 불규칙하게 찢긴 형태.
- 모자와 옷에는 거친 펄프와 구김, 안쪽에는 따뜻한 종이색 적용. 과한 균열 무늬는 완화. Unity 노멀 강도는 0.75.
- 기존 17개 본과 9개 60 Hz 클립, 플레이어 충돌체와 이동 값 유지.

## 결과

- `01-three-quarter.png`, `02-front.png`, `03-rear.png`: 실제 모델 전신 확인.
- `04-paper-detail.png`: 모자·얼굴·목도리·옷의 가까운 재질 확인.
- `08-export-verified.png`: 베이크 재질을 적용한 GLB를 다시 불러와 렌더링.
- `export-check.json`, `rig-check.json`: 메시·재반입 크기·스킨·클립 확인.
- `import-check.txt`, `play-check.txt`, `unity-ingame.png`: Unity의 실제 InGame 씬 참조와 애니메이션 상태 및 조명 확인.

## 제작/적용

`Tools/refine_spirit_layers.py -- model`, `-- bake`, `-- rig` 순서로 Blender 5.1에서 실행. V1/V2 소스를 남기고 V3 소스는 `ArtSource/PaperHoodSpiritV3`에 보존. Rig 출력은 검증 프로젝트로 우선 내보낸다. Unity `SpiritHatReview.RunV3` 검증 후 FBX·4개 텍스처·종이 재질만 원래 에셋 경로에 반영한다. 기존 `.meta`와 프리팹 참조는 유지하며 InGame 씬을 다시 저장하지 않는다.

고밀도 주인공 모델이며 LOD 제작과 플랫폼별 성능 측정은 이번 작업 범위에 포함하지 않았다.
