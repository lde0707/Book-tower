# 도입의 새 노출 시간 · 대화 이후 상호작용 · 상시 목표

- 빛 도착 3.8초부터 새가 나타나고, 4.45초에 완전히 보인다. 이후 3초 동안 유지한 뒤(빛 전달 시작 7.45초) 3인칭으로 전환한다. 대사 글자가 아직 표시 중이면 완료까지 기다린다. F/좌클릭 연타로 이 노출 구간을 건너뛰지 않는다.
- 실제 F 입력으로 재현한 실패: 대화 종료 상태는 정상(StoryActive=false, GamePhase=Playing)이었지만 작업책을 향한 조준 광선이 ‘두꺼운제본상판’ 콜라이더를 먼저 맞춰 TargetInteractor.Current가 비어 있었다.
- 작업책에 가장 가까운 해당 상판에 InteractionTargetProxy를 연결한다. F 대상 선택과 좌클릭 읽기가 같은 책으로 해석한다. 책의 사거리·방 노출 조건은 그대로 확인하며 다른 벽이나 가구를 통과하는 광선으로 바꾸지 않는다.
- 목표의 5초 타이머를 제거했다. 방별 스토리 목표를 보관하고, 아직 지정되지 않은 방은 해당 Room.Goal을 표시한다. 작업책을 읽으면 ‘은박에 빛을 이어 문 옆 잎 문양 깨우기’로 갱신한다. 전체 화면 컷씬/메뉴에서는 숨기며 플레이 화면으로 돌아오면 유지한다.
- 광학 조작부의 안내가 다리의 ‘페이지 내리기/세우기’로 덮어써지던 문제도 수정해 책갈피 당기기·제본실 감기가 올바르게 표시된다.

검증은 실제 Unity Play에서 입력 장치를 통해 F와 좌클릭을 보내 확인한다. 직접 TryRead만 호출하는 기존 검증을 실제 조준/입력으로 강화했다.

검증 완료: 80개 PASS 행(최종 통과 행 포함). 실제 F 광원 조작, 상판 조준 상태의 F/좌클릭 작업책 읽기, 목표 갱신과 5초 초과 유지, 일시정지 복귀, 3초 새 노출 및 F0–1A 스토리 회귀 통과. 검증본과 원본의 변경 C# 파일 해시 일치.
