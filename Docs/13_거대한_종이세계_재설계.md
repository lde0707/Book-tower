# 거대한 종이 세계 · 방별 재설계 V2
작성: 2026-09-25. **설계 제안과 모델링 레퍼런스. 새 퍼즐/지형의 Unity 적용 및 플레이 검증 전.**

## 방향과 범위
기존 16개 방과 이야기 순서를 유지한다. 3A 재방문은 별도 방이 아니라 같은 공간의 두 번째 상태다. 총 17개 상태 보드를 제작한다. 기존 문서의 단일 행동 퍼즐, 네모 방, 70분 분량 제한보다 이번 사용자의 다단계 탐험·거대 공간 요청을 우선한다. 주제인 ‘접힘은 존재, 펼침은 망각’, 스승의 구출과 여행자 기록의 양립 불가능한 결말은 보존한다.

목표 플레이 시간은 본편 110–140분, HD 15–20분의 **미검증 추정**이다. 2F는 쉬는 구간이며 모든 방에 같은 난도의 장치를 억지로 채우지 않는다. 각 방은 관찰→실험→조합→이동/확인으로 이어지되, 주된 추론 방식이 연속해서 반복되지 않게 한다. 필수 상호작용 8–16개, 선택 반응물 3–5개를 기본으로 한다. 개수보다 서로 영향을 주는 관계를 우선한다.

## 공통 제작 규칙
- 캐릭터 기준 높이 1.2u, 기존 충돌 크기 유지. 방 외곽은 56–92u, 소품은 정령의 4–20배. 콜라이더를 줄이지 않고 건축과 소품을 키워 작은 존재감을 만든다.
- 흰 섬유 종이 #FBFAF6 / #F2EFE7, 연필 #3A3733, 따뜻한 회색 그림자 #6E6A63, 빛 #F2C879, 정령 리본 #D9694F. 고색창연한 갈색 도서관·석조 성·금속 기계는 사용하지 않는다.
- 둥근 큰 머리, 검은 타원 눈, 붉은 스카프, 말린 종이 꼬리의 정령 유지. 종이 표면 디테일은 노멀/러프니스 중심, 모든 섬유를 실제 폴리곤으로 만들지 않는다.
- 방마다 3–5개 연결 구역, 시야를 잡는 거대 랜드마크 하나, 되돌아오는 지름길 하나. 허브에서 가까운 목표까지 5–12초, 의미 없는 긴 보행은 피한다.
- 장식은 이동 바깥쪽, 조작물은 손잡이·접지선·외곽선·반응 애니메이션으로 구별. 색만으로 정답 전달하지 않는다. 선택 장식은 빛 경로와 가동 범위를 침범하지 않는다.
- 기본 보행로 폭 4–6u, 교행/관찰 공간 8u 이상, 보통 단차 0.25u 이하 또는 경사로. 점프는 현행 높이 1.2u를 기준으로 수평 거리 실측 후 확정한다. 초안 간격 1.5–2u, 수직 차 0.6u 이하. 낙하 즉시 마지막 안전 섬으로 복귀, 기록·열쇠 보존.
- 귀여운 종이 생물은 공격/체력/드롭 없이 펼쳐졌다 회복. 밟기와 종 유도를 동등한 해법으로 제공. 빠른 입력·정확한 타이밍이 스토리 진행의 필수 조건이 되지 않는다.
- F/클릭 조작, Shift 역접기, WASD 이동, Space 점프, Q/E 90도 카메라 회전 체계 유지. 운반물은 잡고 놓는 단일 조작, 조작 중 점프 강제 금지.
- 종이 접힘의 예비 동작 0.15초, 전개 0.6–1.2초, 안정화 0.2초를 초안으로 한다. 조작 연속 입력은 상태 전환 중 하나만 예약. 성공은 출구/다리/빛의 실제 변화로 보여준다.
- 주 그림자는 단일 태양(Euler 55,-30,0). 보조 조명은 그림자 없음. 반사 퍼즐은 별도 논리 광선+시각 효과이며 일반 URP 재질이 태양을 물리 반사한다고 가정하지 않는다.
- 환경음은 방별 주 재질음 하나와 보조음 둘 이하. 필수 신호는 동작·진동·그림으로도 제공. 문턱에서 1.5–3초 크로스페이드. 반응음 0.1–0.6초, 루프 8–20초 권장. 실제 음원 제작은 후속 작업이다.
- 보행 콜라이더는 단순화하고 시각 메시와 분리. 출입구 옆 연속 벽과 다리 난간으로 우회 통과 차단. 방 문 닫힘 상태에서 중앙/좌우/문틀 바깥 접근 모두 테스트한다.
- 겹침 금지: 동일 면 중복 생성 금지, 이웃 바닥은 경계 공유, 장식 띠는 최소 0.015–0.03u 돌출하거나 하나의 메시/데칼로 통합. 코너 부품은 소유 방향 하나만 지정. 움직이는 모든 접기 상태에도 검사. 하드웨어 깊이 정밀도는 최종 카메라에서 확인한다.
- 길 바닥과 문 판은 충돌 연속성을 유지하되 시각 면이 동일 평면에 겹치지 않도록 전용 접합 소켓을 만든다. 모든 연결은 양방향 통과, 난간 끝, 카메라 회전 시 방 가시성 확인.

## 카메라 명세
좌표는 각 방 중심 원점, +Z 북쪽/출구, +X 오른쪽, +Y 위. 이미지의 C 표식은 개념 표시이며 아래 수치가 블록아웃 기준이다. 문자는 생성 이미지에서 오기될 수 있다.

실제 플레이는 직교 투영, pitch 30°, yaw 기본값에서 Q/E 90° 스냅. **C0 전경**: 남쪽 진입 트리거, 초점은 방 중심, orthoSize=가로·깊이 최댓값×0.58로 2초만 보여준 뒤 C1로 전환. **C1 플레이**: 플레이어와 현재 목표의 가중 중심(0.7/0.3), 아래 표의 초점/size는 해당 구역 시작값. 플레이어가 화면 높이 약 4% 아래로 작아지면 구역을 분할하거나 size를 줄인다. **C2 조사**: 조작 대상 중심+Y1, orthoSize 6–9, 자동 복귀; 카메라 때문에 조작 방향이 달라지지 않게 한다.

카메라 위치는 초점 T에서 카메라 전방 벡터의 반대 방향으로 거리 d=1.5×방 최대 치수만큼 물린다.
forward=(sin(yaw)cos(30), -sin(30), cos(yaw)cos(30)), position=T-d×forward.
예: F0 C1 T=(0,0,0), yaw0, d84 → position=(0,42,-72.75), ortho15.
farClip은 d+최대 치수×2, nearClip은 0.3을 출발점으로 깊이 정밀도 검증.
가림막 벽만 투명/숨김 처리하며 퍼즐 그림자 투사체는 임의 숨김 금지. 플레이 경로를 가리는 장식은 모델 단계에서 제거한다.

3A 왜상은 고정된 C1 정렬 모드 T=(0,4,8), yaw0/pitch30, ortho21에서 시작해 실제 모델 정점의 화면 투영으로 재조정한다. 평행 이동으로 왜상이 맞춰진다고 표현하지 않는다. 면 접힘+카메라 yaw가 조건이고 모든 조각이 뷰포트 안에 있어야 한다. 거대화 후 기존 P15 좌표를 복사하지 않는다.

- **공간/크기**: 갈라진 타원형 책 표지 세 장이 꽃받침처럼 솟은 광장. 56 × 44 × 18u (X/Z/높이, 설계 외곽).
- **해결 흐름**: 찢어진 끈을 당겨 바람개비를 깨움 → 펄럭이는 표지 밑에서 걸쇠 조각 두 개 회수 → 서로 다른 홈에 끼움 → 중앙 누름종이 발판으로 표지를 펼침.
- **상호작용 구성**: 끈 3, 바람개비 2, 걸쇠 조각 2, 홈 2, 누름 발판 1, 선택 종이 꽃 4.

- **사운드**: 종이 가장자리 문지름, 가벼운 딸깍, 첫 개방 시 낮은 종이 울림.

### 05 · 1D 발자국이 자라는 정원

### 06 · 1E 매달린 인장의 저울

- **공간/크기**: 동심원이 끊긴 고리형 발코니와 중앙 모빌. 66 × 66 × 38u (X/Z/높이, 설계 외곽).
- **해결 흐름**: 종이 추 세 개를 다른 가지에 배치 → 무게 균형으로 관측 발코니 높이 맞춤 → 모빌의 세 그림자를 한 인장으로 합침 → 완성 인장이 가리키는 숨은 네 번째 기록 회수.
- **상호작용 구성**: 종이 추 3, 매다는 홈 5, 회전 가지 3, 고정 걸쇠 2, 기록 1, 음향 잎 3.

- **읽히는 이유/실패 대응**: 무한 재귀 구현이 아니라 세 개의 실제 공간을 대응시킴. 크기 변환은 문 통과 연출과 연결된 별도 공간으로 구현. 두 결말 모두 접근 가능.
- **사운드**: 같은 종이 음색을 세 음역으로 반복, 안쪽으로 갈수록 가까운 건조한 소리.
- **모델링 키트/장식**: 중첩 팝업 책 3세트, 8자 길, 크기 대응 문, 소형 장난감.
- **C1 시작 초점**: (0, 3, 0), yaw 90°, pitch 30°, orthoSize 16. C0/C2는 공통 카메라 규칙 적용.
- **레퍼런스**: [HD 보드](ArtReview/RoomRedesignV2/17-HD.png).

## 구현 순서와 검증 게이트
1. F0–1B 수직 슬라이스부터 만든다. 상호작용 그래프의 선행 조건/되돌림/저장 상태를 작성하고, 각 요소의 시각 반응을 먼저 연결한다. 단일 상태 번호보다 조건 집합을 사용해 다양한 탐색 순서를 허용한다.
2. 1A/1B에서 설명 HUD 없이 첫 목표, 접을 대상, 성공 이유를 새 플레이어 3명에게 확인한다. 진행을 말로 알려주지 않고 관찰: 30초 내 목표를 지목, 60초 내 조작 후보 탐색, 성공 후 왜 길이 열렸는지 설명 가능한지 기록. 이는 목표 기준이며 현재 통과했다고 주장하지 않는다.
3. 1C 반사 광로, 1D 생물/종 대체해법, 1E 무게-그림자 제약을 각각 독립 프로토타입으로 검증한다. 이후 2층 기록/접기 그래프로 확장한다.
4. 3A의 실제 면 12개를 제작해 원근 없는 카메라 투영으로 정렬 검증. wrong yaw / wrong fold / 미점등은 실패, 정답은 성공. 장식과 그림자·기록 읽기가 충돌하면 장식을 줄인다.
5. 3A–3B–3C는 북남 역광 축을 먼저 예약하고 나머지 방 외곽을 그 축에 맞춘다. 거대 방 도입 시 월드 좌표와 방 전환 경계를 전부 재배치해야 한다.
6. 모든 방 문 닫힘 우회 접근, 열린 다리 양방향 이동, 회전 네 방향 가림, 각 접기 상태의 겹침, 저장 후 복구, 낙하 후 열쇠 보존을 검사한다. 기존 방 연결 테스트 수치가 새 방 배치까지 보증하지 않는다.
7. 장식/섬유/사운드는 블록아웃 플레이 검증 후 추가. 인스턴싱, LOD, 가시성 구역으로 큰 방의 드로콜·그림자 비용을 제어한다. 목표 하드웨어/프레임 예산은 아직 미정.

## 산출물과 현재 한계
- rooms.json: 17개 상태의 방별 설계 데이터.
- prompts.json: built-in image_gen 생성 프롬프트 세트. 레퍼런스는 사용자 종이 정령 이미지이며 후속 보드는 스타일 정합성을 참고한다.
- index.html: 순서별 이미지와 기믹/카메라 명세 갤러리.
- 생성 이미지의 빛·치수·평면도는 디자인 참고이며 엔진의 충돌, 광선, 왜상 정렬을 증명하지 않는다. 모델 제작은 이 문서의 치수와 검증을 우선한다.
- 이 변경은 새 설계/레퍼런스다. 새 방 16개의 메시, 애니메이션, 오디오, 퍼즐 코드는 아직 Unity 씬에 적용하지 않았다.
- 기존 겹침 수정은 별도 작업으로 빌드 성공, 자동 후보 3231→2832. 가려진 내부 면도 포함하는 후보 수이므로 화면상 결함 개수와 다르며 최종 시각 검증 완료를 뜻하지 않는다.
