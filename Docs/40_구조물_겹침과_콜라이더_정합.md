# 구조물 겹침과 콜라이더 정합

2026-10-07. 요청: 오브젝트의 불필요한 교차 배치를 없애고, 구조물보다 커지지 않는 충돌체로 플레이어 관통을 막는다. 중력 퍼즐·기존 이야기·통로를 보존한다.

## 적용 원칙과 변경

- 새 중력 구조물 16개 방과 F0·1A·1B의 주요 작업대·책장·가구와 벽·천장·아치 1,970개 표면에 보이는 MeshFilter의 원본 메시를 그대로 사용하는 비볼록 MeshCollider를 적용한다. 열린 아치·가구의 빈 공간을 큰 상자로 채우지 않는다. 별도 확장 스케일이나 convex hull을 쓰지 않는다.
- 같은 오브젝트의 이전 기본 콜라이더는 이중 충돌을 피하도록 비활성화한다. 화물 Rigidbody의 기존 운동용 충돌체, 트리거와 보이지 않는 진행 게이트는 이 교체에서 제외한다.
- F0 운반실을 뒤로 4m 이동해 매달린 기존 장식과 분리한다. 해결 후 경첩 위치도 같이 갱신한다. 왼쪽 아치는 접히는 페이지와 떨어지도록 바깥으로 1m 옮긴다.
- 1B 조작대를 방 로컬 z=-8.8로 옮겨 기존 높은 통로와 분리한다. 기존 다리나 아트를 삭제하지 않는다.
- 1C와 1E의 새 아치는 각각 앞으로 5m, 3m 이동해 기존 높은 경사로와 입구가 겹치지 않게 한다.
- 새 관찰 골방 판의 간격을 1.4m, 깊이를 1.05m로 정리한다. 종이 적층·장식 부착·바닥과 벽의 정상적인 접합은 교차 배치 오류로 취급하지 않는다.
- 기존 블록아웃의 주동선 큐브 중 제어 스크립트와 자식이 없고, 월드 꼭짓점(1mm 기준)과 재질까지 같은 중복 11쌍에서 한 겹만 비활성화한다. 유지한 원본 경로와 판별 내역은 `ArtReview/CollisionFit/duplicate-cleanup.txt`에 있다.

작업 전 씬은 `Logs/CollisionFit/InGame-before.unity`에 보존했다. 변경 도구는 `StructureCollisionFit.Apply`이며, 중력 배치 재생성 뒤에도 이 정합을 다시 적용한다.

## 검증 기록

`ArtReview/CollisionFit`에 실제 검사와 카메라 화면을 저장한다. 첫 검사 `Iteration01/checks.txt`는 실패 기록이다. 첫 검사에는 경사로 내부의 시작점 문제가 있었다. `iteration02-checks.txt`는 시작 높이를 보정한 뒤에도 남아 있던 1C·1E의 아치 입구/경사로 교차를 확인한 기록이다. 두 방의 아치를 실제로 이동해 수정했다. 좁고 기울어진 작업대 다리 둘레를 미끄러져 우회하는 것을 관통으로 오인한 F0 가구 검사도 있어, 후속 검사는 넓은 책 수납 가구 표면으로 대상을 바꿨다. 최종 결과는 이후 실행 파일 검사 기록을 따른다.

검사는 16개 실제 물리 해법, 되돌리기와 일시정지, 원본 메시와 콜라이더의 동일성, 실제 CharacterController를 구조물 쪽으로 움직였을 때 막히는지, 아치 개구부를 통과하는지, 첫 세 방과 연결 통로의 이동을 구분한다. 정적 형상 일치가 전체 게임의 모든 동적 접촉 상황을 증명하지는 않는다.

## 최종 결과

- **기능:** `ArtReview/CollisionFit/Standalone/checks.txt`의 Windows 일반 그래픽 실행에서 **319개 PASS / 실패 0**. 16개 실제 물리 해법, 16개 조작대의 플레이어 캡슐 차단, 16개 아치의 개구부 통과, 첫 세 방의 골방 판·대표 가구 충돌, 1B 조작대와 기존 통로의 비겹침, 두 연결 통로 왕복과 측면 동선을 포함한다. 실행 예외가 없었다.
- **문 연출:** `story-checks.txt` 통과. 첫 문 개방 중 이동 잠금·완전 개방 뒤 대사·입력 복귀와 F0–1A 실제 캡슐 이동을 유지했다. `door-reveal.png`를 직접 검토해 접힌 페이지가 문을 가리지 않는 것을 확인했다.
- **형상:** 정합 대상 1,970개 표면. MeshFilter와 MeshCollider가 같은 메시와 Transform을 사용하며 convex=false이다. 2mm 접촉 여유는 물리 안정화를 위한 contactOffset이며 메시 크기를 확장하지 않는다. 얇은 인쇄·봉제선·빛줄기까지 보행 장애물로 만들지는 않는다.
- **조명:** 변경된 구조의 차폐와 간접광 프로브 780개 재계산 완료. `Lighting/indirect-bake.txt` PASS.
- **빌드:** `build.txt` Succeeded, 오류 0, 경고 8. `Builds/GravityPage/AFoldOfLight.exe` 및 같은 폴더의 데이터가 갱신됐다.
- **성능:** Core Ultra 5 225H / Arc 130T, 1920×1080, 품질 1, 제한 없는 일반 렌더링. 해결 후 고정 시점 15초에서 F0 평균 64.01ms / p95 65.64ms, 1A 39.85ms / 42.32ms, 1B 49.14ms / 53.78ms. 약 15.6 / 25.1 / 20.4fps이며 성능 합격을 주장하지 않는다. 배치와 카메라 가림도 달라졌으므로 콜라이더만의 성능 증감으로 해석하지 않는다.

이 기록은 수정한 배치와 구조물 충돌의 검증이다. 모든 장식의 의도된 접합을 제거했다거나, 모든 위치·이동 속도·동적 접촉 조합을 전수 검증했다는 뜻은 아니다. 초기 `plan.txt`의 1,596개는 가구·새 구조물 단계의 목록이며, 이후 첫 세 방의 건축 표면 374개를 포함한 최종 범위는 1,970개다.
