## 생성과 검증

Tools/level_layout.py는 기존 전체 배치의 기반이다. F0는 InteriorF0Builder, 1A는 StorybookRoomBuilder가 별도 모델링 패스를 제공한다. 전체 씬 재생성 시 새 1A 패스를 자동 적용한다고 가정하지 않는다. F0 이후 1A 패스를 적용하고 검증해야 한다.

Unity 6000.3.10f1 사용. F0 검증은 F0PlayVerifier.Run, 1A는 StorybookPlayVerifier.RunBatch. 모델 생성 메서드와 범위는 [1A 기록](ArtReview/Storybook1A/README.md), [F0 기록](ArtReview/InteriorRoomsV3/F0-implementation.md).

최신 1A 생성: `StorybookRoomBuilder.ApplyWorkshop`, 검증: `WorkshopVerifier.RunBatch`. 이전 1A 문서는 과거 구현 기록이며, 새 설계는 [그림자 공방과 전 방 난이도](24_그림자공방과_전방_난이도설계.md)를 따른다. 1B 이후의 새 퍼즐은 설계 상태이며 이번 패스로 제작됐다고 간주하지 않는다.

[1A 플레이 결과](ArtReview/Storybook1A/play-check.txt): 통로·두 아치·출구 이동, 오답 미완료, 세 접이면 완료, 반쪽 정렬 검사. [정리 기록](Maintenance/2026-09-26-cleanup.md): 참조 검사 후 제거한 구버전 콘텐츠.

자동 검사는 이동·판정의 회귀 검사다. 초행 사용자가 설명 HUD 없이 목표·대상·성공 이유를 읽는지는 별도 사용자 테스트가 필요하다.
