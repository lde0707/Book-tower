# 12. 프로토타입 공략 — 지금 빌드에서 실제로 되는 것

> 기획서가 아니라 **지금 씬에 들어 있는 것**만 적었다.
> 데이터(`level_layout.json`)와 퍼즐 스크립트에서 직접 뽑은 값이다.
> 설계 문서와 다르면 이 문서가 맞다 — 구현이 아직 안 따라간 것이다.

## 먼저 알아둘 것 네 가지

1. **퍼즐을 풀어도 문이 열리지 않는다.** `OnSolved` 는 로그와 조명 연출뿐이다.
   어느 방이든 그냥 걸어서 지나갈 수 있다. 막히는 곳은 없다.
2. **마커(`◎목표지점`, `랜드마크_*`)는 화면에 안 보인다.** 빈 GameObject 라
   렌더러도 콜라이더도 없다. "목표 지점에서 확인하고 돌아온다"(P2) 같은
   설계는 지금 성립하지 않는다.
3. 방향은 전부 **화면 기준**이다. 모든 방의 `camYaw` 가 0 이라 방마다 안 바뀐다.
4. 접이면은 `F` 를 누를 때마다 `0 → 1 → 2 → 3 → 0` 으로 돈다. `Shift+F` 는 반대.
   전부 0(납작) 에서 시작한다.

조각만 주우면 안 풀린다. 걸쇠에서 눌러야 한다(사거리 5.6).
