# A Fold of Light — 타이틀 콘셉트 3종

확정 표기: 접힌 빛 — A Fold of Light.

내장 image_gen 도구로 제작한 영문 로고 3안과 메인 화면 배경 3안이다. 최종 프롬프트는 prompts.json에 저장했다.

| 안 | 로고 | 배경 |
|---|---|---|
| A | 종이새·잎·겹종이 글자 | 따뜻한 제본 도서관, 문틈의 빛 |
| B | 글자에 접힌 빛·다이아몬드 문양 | 청록 그림자와 은박 반사광 |
| C | 펼친 책과 두 친구의 여정 | 거대한 책 속 페이지 다리 |

로고: 1536×1024 RGBA, 실제 알파 채널 포함. 글로우/그림자도 반투명 픽셀이므로 최종 UI 배경에 올려 본 뒤 가장자리 조정 가능.
배경: 1672×941 RGB, 약 16:9. 왼쪽은 로고와 세로 메뉴를 위한 여백이며 텍스트는 포함하지 않았다.

추천 조합: 로고 B + 배경 A. 게임의 빛 퍼즐 정체성과 기존 F0의 따뜻한 종이 공간을 연결한다. 더 동화적인 인상은 A+A, 여정과 규모감을 강조하려면 C+C.

이번 결과는 선택용 아트 콘셉트이며 Unity 메인 화면에는 아직 연결하지 않았다. 캐릭터는 콘셉트 수준의 표현으로, 확정안에서 실제 정령/새 디자인과 세부 형태를 맞출 수 있다.
